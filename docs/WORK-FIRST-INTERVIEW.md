# ChatGPT Work에서 쉽게 시작하기

2.20.0의 목표는 챠니 스튜디오 하나를 불러 제품·서비스 자료를 넣고, 짧은 선택으로 제작과 수정까지 이어가는 것입니다.

## 시작

`@chany-studio 내 제품으로 콘텐츠를 만들고 싶어. 필요한 것부터 하나씩 물어봐줘.`

제품 사진 또는 실제 서비스 화면·설명을 첨부하세요. 참고 사진이나 영상 링크·파일이 있으면 함께 넣습니다. 이미 알려준 내용은 다시 묻지 않으며, 보통 무엇을 소개할지·어디에 쓸지·참고 자료 유무 중 모르는 것만 확인합니다. 질문마다 직접 답하거나 “추천해줘”라고 할 수 있습니다. 사진 첨부는 대화창의 첨부 기능을 사용합니다.

## 진행 방식

1. 첨부 자료를 읽고 내 제품·서비스와 참고 자료를 구분합니다. 불분명하면 어느 사진이 내 제품인지 먼저 확인합니다.
2. 필요한 질문을 한 번에 하나씩 합니다. 명확한 부분 수정·누끼에는 새 기획 인터뷰를 붙이지 않습니다.
3. 이미지 제작에서 레퍼런스가 없으면 후보를 실제 이미지로 보여줍니다. 추천 후보 최대 3개를 강조하되 기본 6장이나 요청한 수량을 줄이지 않습니다.
4. 선택한 참고 이미지에서 무엇을 유지할지 확인하고, 만들 결과·확정 문구·전송 자료·실제 비용을 한 번에 안내합니다. 이미 선택한 방향을 다시 고르게 하지 않습니다.
5. 결과를 먼저 보여주고 제품·서비스 일치, 구도, 글자를 각각 확인합니다. “제품이 달라요”, “배치만 바꿔줘”, “글자만 고쳐줘”로 수정할 수 있습니다.

“추천해줘”는 추천을 맡기는 뜻이며 결제 승인은 아닙니다. “그만할래”는 현재 흐름을 중단합니다. 진행 중 생성의 실제 취소·환불 가능 여부는 해당 서비스 상태로 확인합니다.

## 영상 제작으로 시작하기

`@chany-studio 내 제품으로 짧은 소개 영상을 만들고 싶어. 참고 영상도 찾아주고 필요한 것만 하나씩 물어봐줘.`

서비스라면 실제 화면·공간·설명으로 시작할 수 있습니다. 참고 영상이 있으면 링크나 파일을 함께 주세요. 사진부터 따로 만드는 과정을 요구하지 않습니다. 영상에 필요한 기준 이미지가 있는 경우에만 준비하며 이미 승인한 이미지·영상은 재사용합니다.

1. 제품·서비스와 사용할 곳을 확인하고, 알려준 내용은 다시 묻지 않습니다.
2. 참고 영상이 없고 검색을 원하면 영상 후보를 찾습니다. 수량을 정하지 않았다면 3개를 제안하되, 실제로 볼 수 없는 후보는 확인 범위를 표시합니다. 사진 보드으로 대신하지 않습니다.
3. 첫 장면 → 핵심 내용 → 마무리, 길이·화면 비율, 자막·목소리·음악 계획을 짧게 보여줍니다. 비용은 실제 작업 단계별로 확인하며 추천은 결제 승인이 아닙니다.
4. 제작을 요청하고 필요한 승인을 마치면 장면 제작부터 요청한 편집·자막·소리를 거쳐 최종 재생 가능한 영상까지 이어갑니다. 콘티나 영상 조각만으로 완성됐다고 하지 않습니다.
5. “첫 장면을 더 빠르게”, “이 장면의 제품만 고쳐줘”, “자막·목소리만 바꿔줘”처럼 수정합니다. 문제가 있는 구간을 중심으로 고치고 승인한 부분을 재사용합니다.

다른 사람의 영상은 분석한 연출 방식을 참고해 우리 제품·서비스의 새 영상을 만듭니다. 원본에서 제품만 직접 교체하려면 수정 권한이 있는 영상 파일과 해당 기능이 필요합니다. 최종 검수는 제품 모습, 움직임·장면 연결, 자막·소리를 포함하며 확인하지 못한 항목은 따로 표시합니다.

영상 중심 보완은 2.20.0에 포함됩니다. 설치본에는 업데이트 후 새 대화에서 적용됩니다.

## 반복 작업과 연결 문제

확인한 브랜드 정보는 저장 위치와 내용을 확인한 뒤 프로젝트에 남길 수 있습니다. 다른 대화에서 자동으로 기억한다고 약속하지 않습니다. 저장 자료에 실제로 접근할 수 있을 때만 불러오며 이번 요청이 이전 선호보다 우선합니다.

연결이 끊기면 기존 작업과 결과부터 확인합니다. 다시 만들거나 결제하지 않습니다. 연결 문제 때문에 이미 답한 인터뷰를 반복하지 않습니다. 진행 상황은 자료 확인·참고 이미지 찾기·제작·결과 확인처럼 실제 상태만 표시합니다.

## 구현·검증 범위

공통 인터뷰 지침과 다음 단계 결정 도구를 추가하고 모든 기존 스킬이 읽는 초보자 지침에 연결합니다. ChatGPT Work의 현재 질문 도구가 있으면 선택형 질문을 사용하고, 없으면 같은 질문을 짧은 번호 선택으로 이어갑니다. 파일 첨부를 텍스트 응답 전용 질문 도구로 요청하지 않습니다. 별도 버튼 화면이나 이미지 선택 위젯이 설치된 것처럼 표현하지 않습니다.

완료 기준: 알려진 답변 생략, 한 번에 한 질문, 자료 역할 확인, 서비스 설명만으로 기획 시작, 명확한 수정에서 인터뷰 생략, 참조 직접 제공/찾기/생략 분기, 취소와 빈 응답 구분, 기존 작업 회수, 승인 없이 생성하지 않기. 자동 검증과 실제 Work 앱 세션 검증은 구분해 기록합니다.
