ChatGPT Work에서 첫 인스타 레퍼런스 찾기

챠니 스튜디오 설치 → 내 Apify 계정 연결 → 새 Work 대화에서 제품 설명하기. 처음 한 번만 설정하면, 이후에는 제품 설명과 원하는 결과를 평소 말로 요청하면 됩니다. 확인일 2026-11-17 · 설치 파일 2.21.7.

챠니 스튜디오는 제품에 맞는 사례를 고르는 작업 지침입니다. Apify는 인스타그램의 공개 게시물과 지표를 가져오는 서비스입니다. 두 가지를 각각 준비해야 합니다. 개발자 도구나 코딩 프로그램을 설치할 필요는 없습니다.

1. 시작 전에 세 가지만 확인하세요

  1. 본인 ChatGPT 계정에서 Work로 새 대화를 열 수 있나요?
  2. ChatGPT 플러그인 화면 ↗의 추가 메뉴에 플러그인 압축 파일 업로드와 사용자 지정 MCP 서버 추가가 보이나요? MCP는 여기서 외부 서비스를 연결하는 메뉴 이름입니다.
  3. 본인이 로그인할 수 있는 Apify 계정 ↗이 있나요? 없다면 공식 화면에서 가입하고 이용 조건을 직접 확인하세요. 검색에 쓸 잔액·무료 크레딧도 확인합니다.

메뉴가 없으면 먼저 계정에서 사용할 수 있는 기능과 회사·학교의 관리자 정책을 확인하세요. 플러그인 사용, ZIP 업로드, 외부 연결 생성 권한은 서로 다를 수 있습니다. 무조건 특정 유료 요금제로 바꾸라는 뜻은 아닙니다. 회사 계정에서는 관리자에게 “Work에서 챠니 스튜디오 ZIP 설치와 Apify 외부 연결을 사용할 수 있게 해 주세요”라고 요청하면 됩니다. OpenAI 관리자 안내 ↗

처음 설정은 컴퓨터의 웹 브라우저에서 진행하는 것을 권합니다. Codex에만 설치한 상태는 Work Cloud 설치 완료가 아닙니다. 인스타 레퍼런스 검색만 할 때는 Higgsfield·Metricool·영상 생성 서비스를 따로 준비할 필요가 없습니다.

2. 챠니 스튜디오 설치하기

  1. Work용 설치 파일 2.21.7 내려받기 ↗를 누릅니다. ZIP을 풀지 말고 내려받은 파일을 그대로 사용하세요.
  2. ChatGPT 플러그인 화면 ↗을 열고 추가 → 플러그인 압축 파일 업로드를 선택합니다.
  3. 내려받은 chany-studio-work-2.21.7.zip을 선택합니다.
  4. 만들어진 Chany's Studio 상세 화면에서 플러그인 설치를 누릅니다. 업로드만 하고 끝내지 마세요.
  5. 상세 화면에 버전 2.21.7 · 스킬 44개, 설치 후 관리 / 채팅에서 사용해 보기가 보이는지 확인합니다. 화면 명칭은 언어·앱 버전에 따라 조금 다를 수 있습니다.

‘데스크톱 앱에서 열기’만 보인다면 Work용 파일인지 확인하세요. GitHub 전체 소스 ZIP이나 다른 플랫폼용 파일 대신 위 Work용 ZIP을 사용합니다.

이 배포 방식은 각자가 ZIP을 올려 본인 계정에 설치하는 방식입니다. 제작자의 개인용 플러그인 상세 주소를 다른 사람에게 보내는 것만으로 설치되지 않습니다. 공개 플러그인 스토어에서 검색·원클릭 설치까지 검증된 배포는 아닙니다.

제품사진으로 시작할 때

사진 레퍼런스 검색에는 Apify 연결이 필요하지 않습니다. Work 대화의 플러그인 선택에서 Chany’s Studio를 고르고 제품사진을 첨부하세요. 설치 상세의 사진 시작 예문을 사용해도 됩니다. 아무 플러그인 선택 없이 사진만 보낸 시험에서는 사진·영상 중 목적을 묻고 멈췄으므로, 모든 빈 대화에서 사진만으로 자동 검색된다고 보장하지 않습니다.

제품사진을 첨부하고 “레퍼런스 찾아줘”라고 하면 사이트를 묻지 않고 Behance에서 찾습니다. Behance 후보를 보여주면 원하는 번호를 고릅니다. 실제 제품 원본과 선택한 사진이 함께 생성 입력에 들어가며, 제품 외형·라벨과 참고사진의 구도·빛을 따로 확인합니다. 무료 검색만 요청한 경우 유료 검색을 시작하지 않습니다. AI 생성만 요청한 경우 코드 합성으로 바꾸지 않습니다. 정확한 글자와 구도는 실제 결과를 확인해야 하며 자동으로 보장되지 않습니다.

3. 내 Apify 계정 연결하기

이미 같은 Work 계정에 Apify를 연결했다면 새 연결을 중복 생성하지 말고 기존 연결 상태를 확인하세요. 이번 확인에서는 공개 플러그인 검색으로 Apify를 찾지 못해 아래 공식 사용자 지정 연결 경로를 사용했습니다. 검색 결과는 계정·시점에 따라 달라질 수 있습니다.

  1. ChatGPT의 플러그인 → 추가 → 사용자 지정 MCP 서버 추가를 선택합니다.
  2. 아래 값을 입력합니다.
화면 항목입력할 내용
이름Apify
설명이 있으면공개 인스타그램 릴스와 반응 지표를 찾는 서비스
서버 URLhttps://mcp.apify.com
인증 방식OAuth
Client ID / Client Secret이 있으면비워둡니다. 이 OAuth 연결에는 직접 입력하지 않습니다.
  1. 외부 연결 안내를 읽고 진행합니다. 플러그인으로 만들기 / Create as a plugin을 누르고 Apify 연결 화면으로 이동합니다.
  2. 본인의 Apify 계정으로 로그인합니다. 계정 선택 화면이 나오면 본인이 사용할 개인 계정 또는 허가받은 팀 계정을 고릅니다. 제작자의 이름이나 ‘찬준 Personal’을 찾을 필요가 없습니다.
  3. ChatGPT가 요청하는 계정 접근·검색 실행 권한과 이용 조건을 직접 확인하고 승인합니다.
  4. ChatGPT로 돌아온 뒤 Apify 연결 완료, 사용 가능한 도구 또는 관리 / 채팅에서 사용해 보기를 확인합니다. 설치 목록에 이름만 있는 경우에는 연결 상태까지 확인하세요.

OAuth는 비밀번호를 대화에 알려주는 대신 Apify 화면에서 연결을 승인하는 방식입니다. API 키·비밀번호·인증 코드를 챗봇 대화에 붙여 넣지 마세요. Apify 공식 연결 안내 ↗

예전 화면에서는 설정 → 앱 및 커넥터 → 만들기로 표시될 수 있고, 개발자 모드가 필요한 경우도 있습니다. 현재 계정에 실제로 보이는 메뉴를 따르세요. 메뉴가 제한됐다면 관리자 허용이 먼저입니다.

4. 새 Work 대화에서 첫 검색하기

설치와 연결을 끝낸 뒤 새 대화를 열고 Work를 선택합니다. 아래 문장의 대괄호만 내 제품에 맞게 바꿔 넣으세요. 참고 링크나 검색 도구 이름을 먼저 알아올 필요는 없습니다.

복사 → 내 정보로 바꾸기 → AI 대화에 보내기
내 제품은 [제품명]이고, [핵심 특징]이 장점이야. [보여주고 싶은 사용 장면]이 잘 드러나는 인스타 릴스 3개를 찾아줘. 제품에 맞는 이유와 확인 가능한 재생수·좋아요·공유수를 비교해줘. 검색 전에 예상 비용과 전체 사용 한도를 알려줘.

제품이 아직 없으면 공개 제품으로 연습할 수 있습니다.

복사 → 내 정보로 바꾸기 → AI 대화에 보내기
COSRX Advanced Snail 96 Mucin Power Essence는 보습용 에센스야. 늘어나는 점성과 가볍게 펴 발리는 제형을 보여주고 싶어. 이 제품 홍보에 참고할 인스타 릴스 3개를 찾아줘. 제품에 맞는 이유와 확인 가능한 재생수·좋아요·공유수를 비교하고, 검색 전에 비용과 한도를 알려줘.

챠니가 검색 범위와 비용을 제시하면 확인하고 승인하세요. 예를 들어 아래처럼 한도를 지정할 수 있습니다. 이 문장을 보내면 그 한도 안의 검색 사용을 승인하는 뜻입니다.

복사 → 내 정보로 바꾸기 → AI 대화에 보내기
이번 검색 전체를 기존 Apify 잔액·무료 크레딧에서 총 0.10달러 이내로 진행해줘. 이 한도로 부족하거나 한도를 강제로 지킬 수 없으면 실행하지 말고 알려줘. 새 결제나 요금제 변경은 하지 마.

0.10달러는 예시 상한이지 고정 가격이나 무료 보장이 아닙니다. 실제 검색기의 현재 가격·건수·잔액에 따라 달라집니다. ChatGPT 이용 요금과 Apify 검색 사용량은 별개이고, 비용은 연결한 Apify 계정에서 처리됩니다.

5. 제대로 연결됐는지 확인하기

연결을 끝냈다는 안내만으로 검색 성공이 확인되지는 않습니다. 첫 결과에서 다음을 보세요.

  • 작업 기록에 Apify 사용이 표시되나요? 일반 웹 검색만 했는데 Apify로 검색했다고 설명하면 확인이 필요합니다.
  • 실제 인스타그램 링크와 제품에 맞는 이유가 있나요?
  • 재생수와 좋아요의 확인 시점·출처를 구분하나요? 후보가 부족하면 부족하다고 알려야 합니다.
  • 공유수를 못 가져오면 확인 불가라고 표시하나요? 0이나 추정값으로 채우면 안 됩니다.
  • 오래된 게시물은 과거 사례로 구분하나요? 검색 표본의 인기 순위가 인스타그램 전체 순위나 매출 성과를 뜻하지는 않습니다.

Apify 무료 계정에서는 이번 검증 당시 공유수 수집이 지원되지 않았습니다. 원문 화면에서 수치가 보이고 접근 가능한 경우에만 별도로 확인할 수 있습니다. 자동 검색은 설치된 기능 중 작업에 맞는 도구를 선택하는 방식이므로, 모든 요청에서 같은 경로가 보장되지는 않습니다. OpenAI 플러그인 사용 안내 ↗

연결이 의심되면 새 대화에서 아래처럼 비용 없는 점검부터 요청하세요.

복사 → 내 정보로 바꾸기 → AI 대화에 보내기
새 검색이나 비용을 발생시키지 말고 설치·연결 상태만 점검해줘. 챠니 스튜디오의 레퍼런스 지침과 연결된 Apify 도구를 이 Work 대화에서 사용할 수 있는지 각각 확인해줘. 연결된 도구를 못 찾으면 실행했다고 하지 말고 빠진 단계만 알려줘.

7. 다른 계정에서도 되는지, 어디까지 확인했나요?

제작자 계정에 고정된 패키지는 아닙니다. 다만 다른 사람의 계정에서 설치부터 검색까지 완료한 실검증은 아직 없습니다.

확인 항목2026-11-17 확인 결과(실행 검증 2.21.1)
로그인 없이 설치 파일 다운로드공개 주소에서 인증·쿠키 없이 다운로드 성공
배포 파일 내용2.21.1 · 44개 스킬 · 총 278개 파일. 공개 소스의 스킬·자료와 일치
제작자의 계정에 묶인 설정제작자 전용 연결 ID, 인증정보, 로컬 사용자 경로 등 검사 항목에서 발견되지 않음
실제 Work 새 대화제작자 계정에서 챠니 지침 선택 → Apify 12개 검색 → 6개 상세 조회 → 3개 추천 성공
다른 사용자 계정의 처음 설치·검색미검증. 본인 계정의 Work·업로드·외부 연결 권한과 Apify 잔액이 필요

이전 2.21.2는 이 실검증을 바탕으로 설치·연결 도움말과 지표 출처 구분을 플러그인에 반영한 버전입니다. 다른 계정에서의 새 실행을 추가 검증한 것은 아닙니다.
