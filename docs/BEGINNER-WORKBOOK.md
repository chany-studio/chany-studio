# CHANY STUDIO · 처음 만드는 AI 이미지와 영상

왕초보 실습 교안 · 2026.09.20 수업용 · 플러그인 2.15.0 기준

**오늘의 목표:** 내 자료로 이미지 한 장을 기획하고, 비용을 확인해 제작하고, 원하는 부분을 수정하는 방법을 익힙니다. 그다음 승인한 이미지를 짧은 영상으로 연결합니다. 전문용어와 모델 이름을 외우는 수업이 아닙니다.

처음부터 전부 읽지 않아도 됩니다. 수업에서는 1~6장을 따라 하고, 혼자 복습할 때는 7장의 필요한 요청문만 복사하세요. 생성 대기시간과 개인별 연결 상태에 따라 실습 속도는 달라집니다.

## 1. 플러그인은 무엇이고, 어디에서 쓰나요?

**Chany’s Studio는 Claude나 ChatGPT 안에서 쓰는 콘텐츠 제작 안내서 겸 작업 연결 도구입니다.** 내가 원하는 결과를 말하면 필요한 질문을 하고, 사진을 살펴보고, 기획·문구·제작·검수 순서를 연결합니다. 독립적인 이미지 생성 사이트나 무료 크레딧 묶음은 아닙니다.

| 구분 | 쉬운 설명 | 내가 하는 일 |
| --- | --- | --- |
| Claude / ChatGPT | AI와 이야기하는 작업 공간 | 이곳의 대화 입력창에 사진과 요청을 보냅니다 |
| Chany’s Studio 플러그인 | 작업 방법을 알려주는 제작 지침과 기능 모음 | 설치한 뒤 원하는 결과를 평소 말로 요청합니다 |
| Higgsfield 등 연결 서비스 | 실제 이미지·영상을 만드는 제작 도구 | 연결·로그인·이용 가능 모델과 비용을 확인합니다 |
| 이 홈페이지·교안 | 사용법과 복사할 요청문을 보는 곳 | 읽고 요청문을 복사합니다. 여기서 생성이 시작되지는 않습니다 |

**플러그인 설치와 제작 도구 연결은 별개입니다.** 대화에서 기획은 가능한데 이미지 생성이 안 된다면 연결이나 권한을 먼저 확인하세요. 사용하는 앱·계정·요금제·관리자 정책에 따라 보이는 기능이 다를 수 있습니다.

### 시작 전 준비물

- 사용할 Claude Cowork 또는 플러그인을 사용할 수 있는 ChatGPT 작업 환경
- 설치된 Chany’s Studio와 연결된 제작 서비스. 실습 전에 로그인·잔액 확인
- 내가 사용할 권리가 있는 사진 1~3장, 또는 제품·서비스를 설명한 짧은 글
- 정확한 제품명·서비스명, 공개해도 되는 사실 정보, 원하는 게시 위치
- 있으면 좋은 것: 좋아하는 참고 사진 1장, 로고 원본, 브랜드 색

개인정보가 담긴 고객 사진·계약서·미공개 자료는 무심코 올리지 마세요. 연습용으로 만든 가상 자료를 쓰면 반드시 가상이라고 말합니다. 사실이 아닌 고객 후기나 실제처럼 보이는 성과를 만들면 안 됩니다.

### 설치가 아직 안 되어 있다면

공식 저장소는 [chany-studio/chany-studio](https://github.com/chany-studio/chany-studio)입니다. 사용하는 앱의 플러그인/마켓플레이스에서 이 저장소를 추가해 Chany’s Studio를 설치하고, 제작 서비스 연결을 승인한 뒤 새 작업을 여세요. 화면 이름이 다르거나 메뉴가 없으면 [설치 설명서](https://github.com/chany-studio/chany-studio/blob/main/docs/INSTALL-AND-UPDATE.md)를 확인하세요. 설치 메뉴가 없는데 이미 설치됐다고 가정하지 않습니다.

```text
Chany’s Studio로 작업하고 싶어. 지금 이 대화에서 플러그인과 이미지·영상 제작 연결을 사용할 수 있는지 확인해줘. 아직 생성하거나 비용을 쓰지 말고, 부족한 준비가 있으면 쉬운 말로 알려줘.
```

설치는 됐는데 제작 연결만 안 되어 있다면 “지금 사용하는 앱에서 Higgsfield 연결을 여는 방법을 알려줘. 나는 직접 로그인할게. 연결 전에는 기획만 해줘”라고 요청하세요. 해당 앱의 설정에서 커넥터·앱·연결 항목을 확인합니다. 메뉴가 없거나 관리자가 제한했다면 우회하지 말고 [문제 해결](https://github.com/chany-studio/chany-studio/blob/main/docs/TROUBLESHOOTING.md)을 보세요. 비밀번호나 인증 코드를 대화에 붙이지 않습니다.

## 2. 실제로 사용하는 순서: 사진을 주고, 말을 걸고, 확인하기

**자료 전달 → 목적 설명 → AI의 제안 확인 → 비용 승인 → 결과 확인 → 필요한 부분 수정**

1. AI 앱에서 새 대화나 작업을 엽니다. 홈페이지의 검색창이나 주소창이 아니라 **AI의 대화 입력창**을 사용합니다.
2. 앱의 파일 첨부 버튼으로 사진·문서를 넣습니다. 프로젝트 폴더에 있다면 그 폴더를 앱에 연결하고 파일명을 알려 주세요. 내 컴퓨터에 있다는 이유만으로 AI가 볼 수 있는 것은 아닙니다.
3. 원하는 결과를 입력하고 보냅니다. 아래의 요청문을 복사해도 됩니다. 이미지 첨부는 AI가 분석하도록 전달하는 단계입니다. 외부 제작 서비스로 보낼 때는 **어떤 파일을 어느 서비스로 보내는지 먼저 확인·승인**합니다. 이 설명이 들어 있는 제작 확인 카드에서 함께 승인할 수 있습니다.
4. AI가 질문하면 선택지나 짧은 문장으로 답합니다. 이미 알려 준 내용은 반복하지 않아도 됩니다. 모르겠으면 “추천해줘”라고 답하세요.
5. 제안에 **만들 것·장수/길이·문구·사용할 자료·제작 도구·실제 비용**이 맞는지 확인합니다. 맞으면 “이 조건으로 진행해줘”, 아니면 바꿀 부분을 말합니다.
6. 결과가 나오면 제품·글자·수량·색을 원본과 비교합니다. 영상을 만들었다면 처음부터 끝까지 재생해 소리까지 확인합니다.
7. “제품은 그대로, 배경만 밝게”처럼 수정합니다. 수정에도 비용이 들 수 있으니 추가 비용을 확인하세요. 최종 파일이나 다운로드 링크를 받고 다시 열어 확인합니다.

결과 카드의 다운로드·저장 버튼이나 제공된 파일 링크를 눌러 내 컴퓨터에 저장하세요. 저장한 파일을 직접 열어 이미지가 보이거나 영상이 재생되는지 확인합니다. `브랜드_피드광고_01`처럼 알아볼 이름으로 보관하고 원본은 따로 남겨 두세요. 링크는 만료될 수 있고, 새 대화에서는 이전 결과를 다시 첨부하거나 프로젝트에서 접근하게 해야 할 수 있습니다.

### 어느 앱에서 어떻게 부르나요?

| 환경 | 가장 쉬운 시작 | 프로젝트 설정이 필요할 때 |
| --- | --- | --- |
| Claude Cowork | “이 사진으로 인스타 광고 한 장 만들어줘” | `/project-studio` 뒤에 프로젝트 설명 |
| ChatGPT Work | “Chany’s Studio로 이 사진을 광고로 만들어줘”; 스킬 선택이 보이면 `@chany-studio` | 스킬 선택에서 `@chany-project` 또는 자연어로 설정 요청 |
| Codex | 자연어 또는 `$chany-studio` | `$chany-project` |

ChatGPT의 `/project-studio`는 모든 화면에서 작동하는 등록 명령이 아닙니다. Claude의 질문 카드도 다른 앱에 똑같이 표시된다고 보장할 수 없습니다. 질문 UI가 없으면 같은 내용을 번호 선택이나 일반 대화로 진행합니다.

### 프로젝트는 꼭 만들어야 하나요?

**한 번 만들 이미지라면 바로 요청해도 됩니다.** 같은 브랜드 작업을 반복할 때만 프로젝트 설정을 권합니다. 제품 정보·목적·금지사항을 기억할 작업 지침을 정리하는 과정입니다. 설정만으로 이미지가 생성되거나 결제되지는 않습니다.

폴더를 다룰 수 있는 환경에서는 설정 승인 후 공통 지침인 `AGENTS.md`와 간단한 기획·작업 상태 파일을 만듭니다. Claude는 `CLAUDE.md`를 통해 같은 지침을 읽습니다. 파일 이름을 외울 필요는 없고, 저장 위치와 변경할 내용을 확인하면 됩니다. 기존 파일이 있으면 통째로 덮어쓰지 않도록 확인하세요. 폴더 쓰기가 불가능한 환경에서는 지침 초안을 받으며, 자동으로 클라우드 프로젝트를 만들었다고 간주하지 않습니다.

```text
[브랜드·프로젝트 이름] 작업을 설정해줘.
우리는 [제품·서비스·공간·행사]를 소개하고, 주로 [보는 사람]에게 보여줄 거야.
목표는 [구매 / 문의·예약 / 브랜드 기억 / 정보 이해·저장 중 하나]야.
주로 [게시 위치]에 쓸 [이미지·캐러셀·영상 등 필요한 것]을 만들 거야.
참고 자료는 첨부했어. 이미 알 수 있는 것은 다시 묻지 말고, 필요한 핵심만 최대 3개 질문해줘.
저장할 지침과 위치를 먼저 보여줘. 승인하기 전에는 파일을 바꾸거나 유료 생성하지 마.
```

Claude에서는 위 요청 맨 앞에 `/project-studio`를 붙이면 됩니다. 설치·업데이트·프로젝트 설정 뒤에는 새 작업을 열어 지침이 읽히도록 하고, 필요한 자료가 실제로 접근 가능한지도 확인하세요.

## 3. 만들면서 익히는 기본 개념 10개

| 말 | 쉽게 이해하기 | 실습에서 하는 행동 |
| --- | --- | --- |
| 생성 | 사진을 그대로 복사하는 대신 새로운 결과를 만드는 것 | 제품이나 글자가 바뀔 수 있어 결과를 확인합니다 |
| 프롬프트 | AI에게 보내는 작업 요청문 | “누구에게, 무엇을, 어디에, 어떻게”를 적습니다 |
| 모델 | 제작 작업을 수행하는 엔진 | 이름을 외우지 않고 목적에 맞는 추천을 받습니다 |
| 원본 | 실제 제품·인물·글자의 기준이 되는 자료 | 형태·라벨·색·사실 정보는 이것을 기준으로 지킵니다 |
| 레퍼런스 | 원하는 느낌을 보여주는 참고 자료 | 구도·빛·분위기를 참고하고 타사의 로고·문구는 복사하지 않습니다 |
| 비율 | 화면의 가로와 세로 관계 | 세로 피드, 긴 세로 영상, 가로 화면 중 어디에 쓸지 말합니다 |
| 해상도 | 그림을 이루는 픽셀의 수, 즉 출력 크기 | 크게 쓴다면 필요한 크기를 확인합니다. 픽셀이 많아도 틀린 글자는 그대로일 수 있습니다 |
| 크레딧 | 제작 서비스가 작업 비용을 계산하는 단위 | 실제 견적·잔액을 확인하고 장수·길이가 늘면 다시 확인합니다 |
| 편집 | 이미 있는 결과의 일부를 바꾸는 것 | “무엇은 그대로, 무엇만 바꿔줘”라고 말합니다 |
| 검수 | 결과가 목적·원본·문구와 맞는지 확인하는 것 | 보기 좋은지만 보지 말고 틀린 제품·글자·동작도 찾습니다 |

**AI 생성은 정확한 복사나 자동 완성을 보장하지 않습니다.** 같은 요청에서도 결과가 달라질 수 있습니다. “더 비싼 모델”, “더 큰 해상도”, “긴 프롬프트”가 항상 더 좋은 결과를 의미하지 않습니다.

### 화면 비율과 크기는 다릅니다

4:5는 비교적 짧은 세로 화면, 9:16은 휴대폰을 꽉 채우는 긴 세로 화면, 16:9는 일반적인 가로 화면의 예입니다. 이는 모양의 예시이지 모든 플랫폼·모델에서 항상 지원된다는 뜻은 아닙니다. “인스타 피드용”, “유튜브 썸네일용”이라고 말하고 현재 지원 규격을 확인받으면 됩니다. 인쇄물은 해상도뿐 아니라 실제 인쇄 크기·여백도 알려 주세요.

### 사진과 영상은 무엇이 다를까요?

사진은 한 장 안에서 대상·빛·배경·글자 배치를 정합니다. 영상은 여기에 **시간과 움직임**이 더해집니다. 제품이 도는 것과 카메라가 제품 주위를 도는 것은 다른 요청입니다. 영상에서는 시작·중간·끝, 컷이 바뀌는 지점, 소리와 자막도 확인합니다.

제품 모습이 중요한 새 영상은 정확한 기준 이미지를 먼저 확보하면 방향을 고정하기 좋습니다. 이미 승인한 이미지가 있다면 재사용합니다. 기존 영상의 배경만 바꾸는 작업에 새 이미지를 무조건 생성할 필요는 없습니다.

이후 나오는 **캐러셀**은 옆으로 넘겨 보는 여러 장의 게시물, **이미지 모듈**은 상세페이지 각 부분에 넣을 이미지, **훅**은 첫 순간 관심을 끄는 장면·문구, **CTA**는 “예약하기”처럼 다음 행동을 안내하는 말입니다. 파일을 받는다는 것과 실제 광고를 게시한다는 것도 서로 다릅니다.

## 4. 첫 이미지 실습: 한 장으로 시작하기

### 준비하고 이름 붙이기

제품이면 선명한 제품 사진을, 서비스이면 실제 서비스 설명과 사용할 수 있는 공간·화면·인물 자료를 준비합니다. 참고 사진이 있다면 역할을 구분해 말하세요. 예: “첫 번째 사진은 내 제품, 두 번째 사진은 원하는 분위기야.” 정보가 읽히지 않는 사진은 선명한 원본을 다시 주는 편이 낫습니다.

### 그대로 따라 하는 첫 요청

대괄호는 내 정보로 바꾸고, `/`로 나열된 선택지는 하나를 남깁니다. 모르는 항목은 “추천해줘”, 없는 정보는 “없음”으로 적습니다. 아래 전체 문장을 AI 대화에 붙여넣고 사진을 함께 보내세요.

```text
Chany’s Studio로 첫 이미지를 만들어보고 싶어.
소개할 대상: [제품·서비스·공간·행사 이름과 한 줄 설명]
보는 사람: [처음 접하는 고객 / 비교 중인 고객 / 기존 고객]
목적: [구매 / 문의·예약 / 기억에 남기기 / 이해·저장]
올릴 곳과 수량: [인스타 피드 등], 이미지 1장
내 자료: [첨부파일 이름과 어떤 자료인지]
참고 느낌: [첨부한 참고 사진 / 밝고 깨끗하게 / 알아서 추천]
꼭 지킬 것: [제품 형태·라벨·로고·공간 구조·확정 문구 등]
이미지에 넣을 문구: [정확한 문구 / 넣지 않음 / 사실에 근거한 초안 추천]
없는 가격·할인·후기·효과는 만들지 마.
부족한 핵심만 질문하고, 방향·문구·사용할 자료·모델·실제 비용을 먼저 보여줘.
외부 전송이 필요하면 보낼 파일과 대상 서비스를 먼저 알려주고 함께 승인받아줘.
내가 그 조건을 승인하면 1장만 만들고, 원본과 다른 부분이 없는지 확인해줘.
```

### 대화는 이렇게 이어집니다

| 차례 | 예시 |
| --- | --- |
| 나 | “이 공간 사진으로 체험 예약을 안내하는 이미지를 만들고 싶어.” |
| AI가 필요한 질문 | “처음 방문할 고객에게 분위기를 보여줄까요, 체험 내용을 설명할까요?” |
| 나 | “처음 오는 사람이 편안하게 느끼도록. 예약 안내 문구는 초안으로 추천해줘.” |
| AI가 제안 | 만들 이미지, 참고 자료, 제안 문구, 보존할 공간, 실제 도구와 비용을 정리 |
| 나의 확인 | 문구와 비용을 읽고 “이 조건으로 1장 진행해줘.” |
| 결과를 본 뒤 | “공간 배치는 그대로 두고, 문구를 줄여서 사진이 더 잘 보이게 해줘. 수정 비용부터 알려줘.” |

위 대화는 설명용 예시입니다. 실제 가격·소요 시간·작동 가능한 도구는 연결 상태에 따라 확인해야 합니다. **생성 요청 전에 문구와 자료 전송 범위를 확인하고, 결과가 나온 뒤에는 게시하기 전에 다시 검수합니다.**

### 사진 한 장 합격 기준

- 내가 전달한 대상이 맞고 제품 모양·개수·라벨·색이 틀리지 않았나요?
- 한눈에 무엇을 보여주려는지 알 수 있나요?
- 작은 휴대폰 화면에서도 핵심 문구가 읽히나요?
- 말하지 않은 가격·혜택·사실이 들어가지 않았나요?
- 내 원본은 남아 있고 결과를 별도 파일로 받을 수 있나요?

## 5. 첫 영상 실습: 승인한 사진에 한 가지 움직임

처음에는 긴 광고 여러 편보다 **짧은 클립 하나와 한 가지 움직임**으로 시작하세요. 아래 5~8초는 실습 희망 길이입니다. 실제 모델이 지원하는 길이·비율·비용을 확인한 뒤 확정합니다.

서비스·공간으로 연습한다면 아래의 “제품”을 “공간 배치와 간판” 또는 “서비스 화면”으로 바꾸세요. 예를 들어 공간 사진은 “가구와 구조는 그대로 두고 카메라만 천천히 가까워지게”가 가능합니다. 실제 없는 직원·고객·시설을 추가하지 않도록 합니다.

```text
방금 승인한 [이미지 파일/대화에서 고른 이미지]로 짧은 영상 1개를 만들고 싶어.
용도는 [릴스·쇼츠·홈페이지 등], 목적은 [제품을 기억하게 / 사용 모습을 이해하게 등]야.
길이는 가능하면 5~8초, 화면은 [긴 세로 / 가로]로 해줘.
[제품은 멈춰 있고 카메라가 천천히 가까워짐 / 카메라는 멈추고 제품이 천천히 회전함] 중 앞에 남긴 동작 하나만 넣어줘.
제품 형태·라벨·색과 배경의 기준은 승인한 이미지를 유지해줘.
새 인물·손·글자는 추가하지 말고, 이번 실습은 음악과 대사 없이 해줘.
이미 승인한 이미지를 다시 생성하지 마.
지원 가능한 움직임·길이·실제 모델·비용과 이미지 전송 범위를 먼저 보여줘.
승인 뒤 제작하고, 처음부터 끝까지 제품과 움직임이 유지되는지 확인해줘.
```

**여기서 배우는 것:** 이미지를 움직이게 만드는 것과 여러 영상을 이어 편집하는 것은 다른 작업입니다. 소리 없는 클립이 완성됐다고 해서 자막·음악이 들어간 완성 광고까지 만들어진 것은 아닙니다. 필요하면 다음 단계에서 자막·오디오·컷 연결을 별도로 요청하세요.

### 영상 한 편 합격 기준

- 처음·중간·끝에서 제품 모양과 로고가 갑자기 달라지지 않나요?
- 제품과 카메라 중 내가 지정한 쪽이 움직이나요?
- 물체가 겹치거나 손·접촉·반사가 이상하지 않나요?
- 끝부분이 갑자기 끊기거나 마지막 제품이 찌그러지지 않나요?
- 요청 길이·화면 방향·소리 유무가 맞고 최종 파일이 재생되나요?

## 6. 프롬프트는 길게보다, 역할이 분명하게

기억할 문장은 하나입니다. **“이 자료로, 누구에게, 어떤 반응을 얻을, 무엇을 만들어줘. 이것은 지키고, 부족한 것은 물어봐.”**

| 빠진 요청 | 조금 더 쓸 만한 요청 |
| --- | --- |
| “고급스럽게 해줘” | “색을 2~3가지로 줄이고 여백을 넓게, 제품이 먼저 보이게 해줘.” |
| “블러 처리해줘” | “제품과 라벨은 선명하게, 뒤쪽 배경만 부드럽게 흐리게 해줘.” |
| “화장품 화보처럼” | “제품의 반짝이는 재질이 보이되 라벨에는 강한 반사가 생기지 않게 해줘.” |
| “영상 역동적으로” | “카메라는 고정하고 제품이 한 번 천천히 회전하게 해줘.” |
| “전환 잘 나오게” | “비교 중인 고객이 실제 차이점 한 가지를 이해하고 구매 페이지로 이동하도록 해줘.” |

빛·카메라·조리개 같은 전문용어는 요청할 때만 배워도 됩니다. “왜 이 방식을 추천했는지 쉬운 말로 알려줘”라고 하면 됩니다. 모델은 AI가 현재 연결에서 가능한 후보를 확인해 추천합니다. 정적 이미지 기본값은 GPT Image 2.5이며, 더 적합한 대안이 있으면 구체적 이유와 비용을 보여준 뒤 승인받습니다. 모델 이름이나 제공사의 홍보 문구는 품질·광고 성과 보증이 아닙니다.

### 결과 수정에 가장 잘 쓰는 문장

```text
지금 결과의 [제품·인물·문구·구도 등 잘 나온 부분]은 그대로 유지해줘.
[수정할 위치]의 [한 가지 요소]만 [원하는 상태]로 바꿔줘.
전체를 새로 만들 필요가 있는지 먼저 판단하고, 가능한 부분 편집부터 검토해줘.
바뀌지 않아야 할 영역을 정확히 유지할 수 없다면 실행 전에 알려줘.
추가 비용이 있으면 먼저 확인받고, 원본은 남겨 새 버전으로 제공해줘.
```

## 7. 목적별 복사 프롬프트: 내 업종으로 바꿔 쓰기

아래 분류는 **업종이 아니라 만들 결과**를 기준으로 나눴습니다. 카페·화장품·교육·상담·호텔·앱·행사 등 자신의 대상에 맞춰 바꾸세요. 사실 자료가 없으면 그 부분을 지어내지 않게 하고, 실제로 없는 공간·기능·후기는 추가하지 않습니다. 각 요청문은 독립적으로 복사해 쓸 수 있습니다.

### A. 제품 누끼·쇼핑몰 기본 사진

```text
첨부한 [제품 사진 파일명]에서 제품 배경만 제거해줘.
목적은 [쇼핑몰 등록 / 다른 디자인에 합성]이야. 결과는 제품 1개가 담긴 투명 배경 PNG 1장으로 받고 싶어.
제품의 형태·색·재질·라벨·로고·반투명 부분은 원본 기준으로 유지해줘.
그림자는 [제거 / 자연스럽게 유지]해줘. 제품을 새로 그리지 않는 배경 제거 방법부터 검토해줘.
실제 투명 배경인지, 가장자리에 흰 테두리나 잘린 부분이 없는지 확인해줘.
도구와 비용·외부 전송이 필요하면 먼저 알려주고 승인받아줘. 원본은 보존해줘.
외부 전송 전에는 보낼 파일과 대상 서비스도 알려줘.
```

### B. 연출 사진·브랜드 대표 이미지

```text
[제품·서비스·공간 이름]을 소개하는 대표 이미지 1장을 만들어줘.
목적은 [기억에 남기기 / 문의 / 구매], 보는 사람은 [대상], 게시 위치는 [채널]이야.
[파일1]은 실제 대상의 기준이고 [파일2 또는 없음]은 원하는 분위기 참고야.
참고 자료의 구도·빛·색 분위기를 반영하되 그 안의 제품·로고·문구는 가져오지 마.
내 대상의 [반드시 지킬 특징]을 유지하고 [일상 장면·배경]에 자연스럽게 배치해줘.
문구는 [넣지 않음 / 정확한 문구]으로 해줘. 비율은 게시 위치에 맞춰 추천해줘.
참고 자료가 충분하면 새 검색은 생략하고, 방향·입력·모델·비용 확인 후 승인받아 제작해줘.
외부 전송 전에는 보낼 파일과 대상 서비스를 알려주고 승인받아줘.
```

### C. 인스타 홍보·매거진형 캐러셀

```text
[제품·서비스·공간·주제]를 소개하는 인스타 캐러셀 1세트를 [5]장으로 만들어줘.
보는 사람은 [대상], 목적은 [내용 이해·저장 / 브랜드 소개]야. 판매 문구는 [필요 / 불필요]해.
내용의 사실 기준은 [첨부 자료 또는 직접 적은 내용]이야. 없는 수치·효과·후기는 만들지 마.
첫 장은 주제를 바로 알게, 중간은 한 장에 한 가지 내용, 마지막은 요약과 목적에 맞는 마무리로 구성해줘.
매거진처럼 큰 제목·적당한 여백·명확한 사진 배치를 쓰고 글꼴·색·여백 규칙은 통일해줘.
참고 이미지는 [파일 또는 없음]. 제품 원본과 참고 스타일의 역할을 구분해줘.
장별 문구와 순서를 먼저 보여주고, 필요한 이미지 수와 총 비용 승인 후 제작해줘.
각 장을 별도 파일로 주고 모바일에서 읽히는지 확인해줘. 전체를 한 장의 콜라주로 끝내지 마.
외부 전송 전에는 보낼 파일과 대상 서비스를 알려주고 승인받아줘.
```

### D. 유튜브 썸네일·인스타 커버

```text
[유튜브 영상 / 인스타 릴스]의 [썸네일 / 커버] 1장을 만들어줘.
실제 콘텐츠는 [영상 주제와 핵심 내용 2~3문장], 보는 사람은 [대상]이야.
사용 가능한 사진은 [첨부 파일]이고, 제목 문구는 [정확한 짧은 문구 / 초안 추천]이야.
작은 화면에서 주인공과 핵심 문구가 먼저 보이게 해줘. 영상에 없는 결과나 자극적인 약속은 넣지 마.
유튜브 가로 썸네일과 인스타 커버의 잘리는 위치를 구분하고 현재 게시 위치에 맞춰 추천해줘.
제품·인물의 원본과 브랜드 색 [색 또는 추천]을 지키고, 문구·배치·비용 승인 뒤 만들어줘.
최종 파일의 글자와 실제 화면 크기에서의 가독성을 확인해줘.
외부 전송 전에는 보낼 파일과 대상 서비스를 알려주고 승인받아줘.
```

### E. 매장·행사·모집 포스터

```text
[매장 소식·행사·모집 이름] 안내 포스터 1장을 [온라인 게시 / 실제 인쇄 크기] 용도로 만들어줘.
대상은 [보는 사람], 목적은 [방문 / 신청 / 소식 알림]이야.

이름과 핵심 내용이 먼저 보이고 일정·장소·신청 방법이 빠지지 않게 해줘.
없는 혜택·출연자·마감일은 만들지 마. QR이 필요하면 실제 목적지 [URL]를 확인해줘.
문구·배치·크기·비용을 먼저 승인받고, 날짜·주소·연락처와 인쇄/게시 가능 크기를 검수해줘.
외부 전송 전에는 보낼 파일과 대상 서비스를 알려주고 승인받아줘.
```

### F. Meta 단일 이미지 광고·전환 캐러셀

```text
[제품 또는 서비스]의 [구매 / 문의 / 예약]를 위한 Meta 광고를 만들어줘.
형식은 [단일 이미지 1장 / 캐러셀 1세트 5장 중 하나], 고객은 [대상], 이동할 곳은 [URL 또는 미정]이야.
```
