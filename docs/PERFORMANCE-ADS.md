# 구매 전환 광고 제작 · 2.6.0

Claude와 ChatGPT Work/Codex에서 같은 구매 전략을 영상·단일 이미지·캐러셀로 제작합니다. 생성·편집·브라우저 도구가 실제 연결된 범위에서 실행하며 미연결 기능은 기획/프롬프트와 미완료 단계로 안내합니다.

## 무엇이 달라졌나요?

제품·서비스 자료 → 고객의 구매 이유·장벽 → 필요한 Meta 광고 분석 → 우리 제품에 맞는 기획 → 원하는 형식의 제작 → 카피·CTA·연결 페이지 검수 순서입니다. 이미 있는 분석이나 승인된 기획은 다시 만들지 않습니다.

| 할 일 | 스킬 |
|---|---|
| 왜 구매하는지, 무엇 때문에 망설이는지 | `chany-jtbd-persona` |
| Meta 광고의 디자인·훅·카피·CTA 분석 | `chany-meta-ad-research` |
| 단일 이미지·캐러셀 광고와 광고 게시물 문구 | `chany-ad-creative` |
| 레퍼런스 기반 전환형 광고 영상 | `chany-campaign-video` |
| 여러 형식을 하나의 전략으로 제작 | `chany-studio` |
| 제공된 실제 광고 성과 분석과 다음 실험 | `chany-marketing-brief` |

사진의 조명·분위기·연출은 Pinterest, 실제 광고 영상·이미지·캐러셀 벤치마킹은 Meta 광고 라이브러리입니다. 영상 파일·링크를 직접 주면 기존 영상 수집/분석 절차를 사용합니다. Meta에서 광고를 분석했다고 Pinterest를 추가 검색할 필요는 없습니다.

공개 광고의 게재 기간이나 디자인만 보고 ‘구매 성과가 좋았다’고 확정하지 않습니다. 결과에는 공개 관찰, 출처가 있는 성과 보고, 정확한 소재와 연결된 계정 데이터를 구분합니다. 실제 성과가 없어도 검증할 가설을 세워 제작할 수 있습니다.

## 바로 복사해서 요청하기

두 환경 모두 아래 자연어 요청을 사용할 수 있습니다. 호스트가 명시 선택을 제공하면 ChatGPT Work에서는 해당 `@스킬명`, Codex에서는 `$스킬명`을 선택하세요. Claude는 노출된 플러그인 스킬/자연어를 사용합니다. 일반 ChatGPT 대화가 로컬 플러그인이나 브라우저를 자동으로 사용할 수 있다는 의미는 아닙니다.

### 영상·이미지·캐러셀을 함께

```text
첨부한 제품 사진과 소개서를 바탕으로 구매 전환용 Meta 광고를 만들어줘.
고객이 왜 구매하고 무엇 때문에 망설이는지 먼저 분석해줘.
Meta 광고 라이브러리에서 관련 영상·단일 이미지·캐러셀 레퍼런스를 총 6개 찾아
디자인, 훅, 본문, 제목, CTA를 분석하고 성과 확인 여부를 구분해줘.
우리 제품의 실제 기능과 근거에 맞게 새로 기획해서
15초 영상 1개, 단일 이미지 1개, 5장 캐러셀 1세트로 만들어줘.
이미지 안 문구와 광고 게시물 본문·제목·CTA도 함께 줘.
기획과 유료 생성 비용은 실행 전에 승인받아줘.
```

### 캐러셀만 만들기

```text
이 Meta 광고 링크의 캐러셀 구성과 디자인을 분석해줘.
첨부한 우리 서비스 소개서에 맞춰 상담 신청용 4장 캐러셀 1세트를 제작해줘.
각 카드의 역할과 문구, 실제 서비스 과정, 상담 범위와 CTA를 연결해줘.
가짜 고객 사례나 성과 수치는 만들지 말고, 우리 상담 페이지와 약속이 맞는지도 봐줘.
상담 신청과 최종 계약 성과는 구분해줘. 영상이나 다른 비율은 추가하지 마.
```

### 영상 파일·링크에서 제작하기

```text
이 영상 레퍼런스와 첨부한 제품 설명서를 분석해서 20초 구매 전환 영상을 기획해줘.
확인한 훅·설득 순서·편집 리듬을 우리 제품에 맞게 새로 구성하고,
실제 제품 기능을 보여주는 장면과 구매 CTA를 포함해줘.
접근하지 못한 장면이나 오디오는 추측하지 마.
대본·장면별 프롬프트·광고 본문을 먼저 보여주고 승인 후 제작해줘.
```

### 광고 성과 보고서 분석

```text
첨부한 Meta 광고관리자 보고서를 분석해줘.
정확한 소재·기간·전환 정의를 맞춰 구매 성과와 클릭 지표를 구분해줘.
기존 광고에서 한 변수만 바꾸는 다음 제작안을 제안하되 계정이나 예산은 바꾸지 마.
```

## 확인 기준

광고 라이브러리 접근 범위는 [Meta 공식 안내](https://www.facebook.com/ads/library/api/)를 실행 시 다시 확인합니다. 플러그인의 설치 가능 여부와 실제 도구 연결은 별개이며, Claude의 스킬 패키징은 [공식 스킬 문서](https://code.claude.com/docs/en/skills)를 기준으로 확인했습니다.

## 결과물 확인

- Meta 광고 레퍼런스의 기본 6개(영상·단일 이미지·캐러셀 합계)는 광고 결과물 수나 캐러셀 카드 수가 아닙니다.
- 캐러셀은 카드별 파일과 광고 문구를 줍니다. 한 장짜리 모아보기는 보조 미리보기입니다.
- 13역할은 필요한 설득 요소를 놓치지 않기 위한 가이드이지 13개 결과물 의무가 아닙니다.
- 이미지 생성 기본값은 GPT Image 2.5 (`gpt_image_2_5`)이며 영상 모델은 실제 연결 기능을 따릅니다.
- 기획안, 생성된 클립, 조립된 영상, 게시된 광고는 각각 다른 완료 상태입니다.
- 실제 광고 등록·예산 변경·집행은 이 제작 요청만으로 실행하지 않습니다.
