# 내 제품·서비스를 레퍼런스에 넣기

Chany’s Studio 2.18.0 · 2026-11-17

제품 사진이나 실제 서비스 화면을 첨부하고 원하는 결과를 말하면 됩니다. 모델 이름이나 프롬프트를 공부할 필요는 없습니다. 참고 사진이 없으면 챠니스튜디오가 찾아서 보여줍니다.

## 바로 시작하는 세 가지 요청

**참고 이미지가 있을 때** — 제품 사진과 참고 이미지를 함께 첨부합니다.

> 이 참고 사진의 구도와 배경은 유지하고 제품만 내 제품으로 바꿔줘. 모양과 라벨을 지키고, 먼저 한 장만 만들어줘. 생성 전 비용을 알려줘.

**참고 이미지가 없을 때** — 제품 사진 또는 서비스 자료를 첨부합니다.

> 이 제품에 어울리는 레퍼런스를 대신 찾아줘. 이미지로 보여주고 하나를 추천해줘. 고른 구도로 내 제품을 넣어줘.

**서비스를 보여줄 때** — 실제 서비스 화면·로고·공간 사진이나 확정 문구를 첨부합니다.

> 우리 예약 서비스 화면을 이 레퍼런스의 휴대폰 안에 넣어줘. 실제 화면의 글자와 기능은 바꾸지 말고, 제목은 “예약을 간편하게”로 해줘.

Claude는 자연어로 요청하고, Codex는 `$chany-studio`, ChatGPT Work는 `@chany-studio`로 시작할 수도 있습니다. 단일 이미지의 지정 영역 수정은 `chany-image-edit`, 광고·캐러셀은 `chany-ad-creative`가 이어받습니다. 사용자가 담당 스킬을 모두 고를 필요는 없습니다.

## 만들어지는 순서

1. 원본 제품·서비스 자료와 참고 구도를 확인합니다. 이미 있는 자료를 다시 요구하지 않습니다.
2. “구도 유지하고 교체”인지 “비슷한 느낌으로 새로 촬영”인지 요청에서 판단합니다. 불분명할 때만 짧게 확인합니다.
3. 어떤 자료를 어디에 쓰는지와 실제 생성 비용을 한 번에 보여줍니다.
4. 결과 이미지를 보여주고 제품·라벨, 참고 구도, 유지할 부분을 각각 확인합니다. 필요한 부분만 수정합니다.

정확한 로고·가격·서비스 화면은 가능한 경우 원본과 편집 가능한 글자층을 사용합니다. 생성형 편집으로 나머지 픽셀이 완전히 같다고 약속하지 않습니다. 그것이 꼭 필요한 작업은 실제 마스크·합성 도구가 가능한지 먼저 확인합니다.

## 레퍼런스를 찾는 곳

기존 기본 보드는 Behance 6장입니다. 원하는 사이트와 수량을 말하면 그 요청을 우선합니다. 참고 이미지가 이미 있으면 불필요한 보드를 다시 만들지 않습니다.

기본 검색처는 여섯 곳입니다. 사진은 Behance(기본)·Production Paradise(직접 요청 시), 광고 사례는 인스타그램·Meta 광고 라이브러리, 영상 연출은 Vimeo Staff Picks·Motionographer를 사용합니다. 목적에 맞는 한 곳부터 시작해 최대 두 곳만 검색합니다. 사용자가 직접 준 사이트·영상 링크는 별도로 분석할 수 있습니다. [검색처와 선택 기준](REFERENCE-SOURCES.md).

> 보내준 자료에서 한국 브랜드 제품 사진에 맞는 계정을 골라 실제 게시물 3개를 보여줘. 첫 이미지뿐 아니라 캐러셀 전체를 확인한 범위도 알려줘.

## Metricool은 언제 필요한가요?

**이미 알고 있는 경쟁 계정을 비교하고 우리 콘텐츠 성과까지 살펴볼 때 유용한 선택 기능입니다.** 인스타그램 전체에서 키워드로 예쁜 사진을 찾아주는 도구는 아닙니다. 연결된 브랜드와 사용 가능한 경쟁 계정 자료가 있어야 합니다.

> Metricool에 등록된 경쟁 계정의 최근 30일 게시물과 릴스를 살펴보고, 우리 서비스에 맞는 레퍼런스 3개를 골라줘. 조회 자료가 없으면 공개 사이트에서 찾아줘. 게시하거나 예약하지는 마.

경쟁 계정 등록은 Metricool의 Analytics → Competitors에서 진행합니다. 현재 연결 도구에 등록 기능이 없으면 사용자가 설정할 위치를 안내합니다. [공식 연결 안내](https://help.metricool.com/access-to-instagram-from-metricool-connection-types-and-differences-kcsrb)에 따르면 Facebook을 통한 연결과 Instagram 단독 연결은 경쟁 분석 지원이 다릅니다. [공식 경쟁 분석 안내](https://help.metricool.com/competitor-analysis-ouhue)에서 현재 기록 범위를 확인할 수 있습니다. 플러그인을 설치했다는 이유만으로 경쟁 계정 자료가 채워지는 것은 아닙니다.

자료가 비어 있으면 그 사실을 알려주고 다른 검색을 이어갑니다. 좋아요·댓글 수는 매출 증거가 아니며, 게시물 원본을 실제로 확인한 뒤 추천합니다. Metricool 없이도 제품·서비스 레퍼런스 제작은 가능합니다.

## 새 모델과 기존 작업

새 작업은 GPT Image 2.6을 먼저 검토합니다. 현재 연결에서 확인된 옵션만 사용하며, 기존 프로젝트에서 정한 2.5 또는 다른 모델을 자동으로 바꾸지 않습니다. GIF, 투명 배경, 영상 연장·부분 수정도 작업에 맞을 때 연결합니다. SVG가 제품 사진을 받지 않는 경우처럼 입력이 맞지 않으면 제품 자료를 버리는 대신 가능한 제작 방식을 제안합니다.

드라마·여러 컷 영상은 원래 인물·제품 기준과 장소·소품·직전 장면 상태를 구분합니다. 모든 영상을 7~9초, 480p로 만드는 식의 고정 규칙은 사용하지 않습니다. 실제 대사 길이와 현재 모델이 지원하는 모드를 기준으로 제작합니다.
