# 목적 기반 제작·모델 추천·편집 연결 검토

검토일: 2026-09-19, 교안·릴리스 재검증 2026-09-20. 범위: 2.15.0의 스킬 지침, 연결 경로, 프로젝트 템플릿, 사용 설명서. 아래는 **지침을 따라가며 확인한 정적 시나리오 검토**이며 실제 Claude/ChatGPT 호스트의 대화 실행, 이미지·영상 생성 품질 평가가 아니다.

## 회귀 검증

- 전체 Node 테스트 102개 통과. 기존 94개에 공통 경로 연결, 패키지 내부 문서 링크, 대안 모델 승인, 영상 편집의 불필요한 기준 스틸 생략, 프로젝트 결정 재사용 검사 5개와 교안 원문/HTML 일치·초보자 설명·복사/인쇄 기능 검사 3개를 추가했다.
- 플러그인 패키지 및 39개 스킬 형식 검증 통과. 홈페이지 테스트 13개, 타입 검사와 정적 빌드 통과. 로컬 브라우저에서 교안 제목·목차·본문 표시와 요청문 복사 성공 상태를 확인했다. 초보자 관점 독자 검토 후 연결 실패 다음 행동, 자료 전송 승인, 결과 저장·재첨부, 서비스·공간 영상 적용, 용어 설명을 보완했다.
- 변경된 프로젝트 질문 테스트는 이전의 추가 선호도 카드 요구를 제거하고, 같은 최대 3개 질문 한도 및 무승인 비용·업로드 금지로 바꿨다.
- 모델 목록은 읽기 전용으로 재조회했다. 이미지 34개·영상 41개 항목이 관찰됐으며 별칭·워크플로·후처리가 포함된 수치다. 이 개수나 제공사 설명은 품질 순위가 아니다.
- 유료 생성, 사용자 파일 업로드, 게시, 커밋·푸시·배포는 이 검증에서 실행하지 않았다.

## 대표 요청의 지침 경로

| 요청/조건 | 검토한 경로와 경계 |
| --- | --- |
| 제품 사진만 + "알아서 만들어줘" | 목적이 불명확하므로 원하는 고객 반응부터 질문. 구매 광고나 콘텐츠 형식을 임의 확정하지 않음 |
| 제품 + 스타일 사진 + 인스타 구매 광고 1장 | 이미 주어진 목적·대상·참고 자료 재사용. 새 사진 검색·중복 질문 없이 기획·문구·비용 확인으로 연결 |
| 서비스 설명 + 예약 문의 영상 | 서비스의 실제 설명과 확인된 근거로 기획. 없는 제품 사진·가격·고객 실적을 요구하거나 창작하지 않음 |
| 정보 저장용 잡지형 캐러셀 5장, 구매 문구 제외 | 광고 제작 스킬의 비광고 모드. 장별 정보 역할·일관성을 검수하며 구매 CTA를 강제하지 않음 |
| 영상 주제·사진을 준 유튜브 썸네일 | 실제 콘텐츠 약속과 화면 가독성 우선. 제품 캠페인·구매 목적을 새로 만들지 않음 |
| "제품 누끼만" | 제품 자산 스킬과 지원되는 배경 제거. 마케팅 인터뷰·레퍼런스 검색·전체 재생성 없이 알파·가장자리 검수 |
| "배경만 수정, 나머지 픽셀 그대로" | 이미지 편집 스킬. 지원되는 마스크·합성 검토, 불가능하면 정확한 보존을 보장하지 않고 한계 안내 |
| 허가된 영상의 배경·조명 수정 | 영상 스킬의 편집 분기 → 공통 실행 루프. 원본·시간 구간·오디오·보존 목록을 재사용하며 새 유료 스틸을 필수로 만들지 않음 |
| 긴 원본 + 짧은 구간만 지원하는 편집 모델 | 라이브 입력 제한으로 부적합 경로 제외. 조용한 잘림·분할 추가 결제 없이 구간 확인 또는 대안 제안 |
| "끝 2초 삭제, 자막만 수정" | 일반 영상 조립/편집. 도구·원본 접근을 확인하고 생성형 영상 모델을 불필요하게 호출하지 않음 |
| 공개 릴스 링크 + "내 제품만 넣어줘" | 링크를 관찰 자료와 편집 원본으로 구분. 수정·업로드 권한이 없으면 새 장면 기획, 무단 원본 변형 경로는 선택하지 않음 |
| GPT 기본 모델을 현재 연결에서 확인할 수 없음 | 확인 불가로 기록. 실제 가능한 대안·비용을 제안하고 승인 전 중단; 숨겨진 기본 모델을 GPT로 표시하지 않음 |
| 마스크 입력이 필요한 편집에 대안 제안 | 입력 역할 지원을 확인한 뒤 같은 비용 확인 카드에서 대안의 이유·범위 승인. 전체 프로젝트 기본값은 유지 |
| 모델 호출 시간 초과 | 기존 작업 상태부터 확인. 다른 모델로 자동 재제출하거나 같은 작업을 중복 결제하지 않음 |
| 기존 프로젝트에 구매 광고와 정보 카드 동시 요청 | 공통 목적·원본은 재사용하고 산출물별 목적 차이만 기록. 모든 카드에 구매 문구를 넣지 않음 |
| 프로젝트 초기화에서 목적·채널이 이미 주어짐 | 필요한 나머지만 질문. 추가 선호도 설문 없음. 모델·견적은 실행 때 해석하고 파일 쓰기는 설계 승인 뒤에만 함 |

## 검토 중 해소한 충돌

1. 프로젝트 질문 3개 뒤에 최대 8개 선호도 질문이 붙던 지침을 하나의 질문 한도로 통합했다.
2. 모델 대체를 필수 기능 부재로만 제한하던 정책에, 구체적인 작업 적합성 제안과 기존 비용 확인 카드 승인을 연결했다. GPT 기본값·범위 제한·자동 재시도 금지는 유지했다.
3. 새 영상 제작의 기준 스틸 요구가 기존 영상 편집에도 적용될 수 있어, 영상 소유 스킬·공통 실행 루프·작업 기록에 편집 분기를 연결했다.
4. 초보자에게 기술 프롬프트를 모두 보여주던 프로젝트 템플릿 문구를 내부 기록과 쉬운 확인 카드로 구분했다.
5. 설명서의 항상 두 번 영상 확인·추가 선호도 카드·Higgsfield 정적 이미지는 대체 모델만 가능하다는 오래된 안내를 현재 정책과 맞췄다.

## 남은 실제 환경 검증

Claude와 ChatGPT 각각에서 질문 UI, 참고 이미지 표시, 실제 연결 모델 선택과 견적, 승인 후 생성, 편집의 제품·오디오 보존을 시험해야 한다. 현재 검증만으로 호스트 대화 UI나 최종 콘텐츠 품질을 보장하지 않는다. 설치된 플러그인은 배포 후에도 사용자가 업데이트하고 새 작업을 열어야 할 수 있다.
