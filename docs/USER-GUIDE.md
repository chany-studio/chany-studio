# AI Photo Reference Studio 사용 가이드

## 한 문장으로 시작하기

가장 해상도가 높은 원본 사진을 첨부하고 결과물만 말하면 됩니다.

```text
이 제품 원본을 보존해 프리미엄 여름 캠페인 키비주얼을 만들어줘.
먼저 Behance·Pinterest 레퍼런스 6장을 이미지로 보여주고 내가 고르면 진행해줘.
```

플러그인은 사진에 보이는 제품 형태, 라벨, 재질, 색상과 구조를 먼저 분석합니다. 사용자가 이미 첨부한 사진의 보이는 사실을 다시 문장으로 설명할 필요는 없습니다.

## 입력 체크리스트

### 필수

- 원본 사진 또는 이미지
- 원하는 결과물 종류

### 있으면 좋은 정보

- 사용 목적과 채널
- 비율 또는 픽셀 규격
- 브랜드 컬러, 로고와 가이드
- 정확히 유지할 승인 문구, 가격, 할인, 기간, CTA와 법적 고지
- 타깃 고객과 캠페인 분위기
- 원하는 레퍼런스 이미지와 각 이미지의 역할
- 반드시 바꾸지 말아야 할 부분과 수정 가능한 부분

제품 효능, 가격, 할인율, 날짜와 법적 문구는 플러그인이 임의로 만들지 않습니다. 사용자가 카피 작성을 요청할 수는 있지만, 그 결과는 승인 전까지 초안입니다.

## 레퍼런스 선택 방식

레퍼런스가 필요한 작업의 기본 모드는 `semi-auto`입니다.

1. 제품과 요청을 바탕으로 최대 두 개의 영문 검색어를 구성합니다.
2. Behance와 Pinterest에서만 후보를 찾습니다.
3. 후보 6장을 현재 대화 안에서 바로 볼 수 있는 실제 이미지로 표시합니다. Claude Cowork에서는 `reference-preview` 연결이 공개 미리보기를 네이티브 이미지 콘텐츠로 전달합니다.
4. 각 후보 아래에 출처, 원문 링크, 적합 이유와 Visual DNA를 표시합니다.
5. 사용자가 `1`부터 `6` 중 하나 또는 `자동 선택`을 답합니다.

이미지가 바로 표시되지 않는 후보는 교체해야 하므로 링크만 있는 목록, HTML 파일, 컨택트시트나 별도 아티팩트를 최종 레퍼런스 보드로 사용하지 않습니다. 원문 링크와 HTML은 여섯 이미지가 대화에 표시된 뒤 출처 확인이나 보조 검토용으로만 제공할 수 있습니다.

처음부터 자동 진행하려면 다음처럼 요청하세요.

```text
레퍼런스도 자동 선택해서 키비주얼까지 진행해줘.
```

사용자가 직접 레퍼런스를 첨부했다면 이미 선택된 것으로 간주하며 별도 검색을 생략할 수 있습니다.

## 작업 유형별 프롬프트

### 1. 누끼와 팩샷

```text
이 제품을 원본 픽셀과 라벨을 보존한 투명 배경 PNG 누끼로 만들어줘.
같은 원본으로 #FFFFFF 배경의 정면 팩샷도 만들어줘.
```

투명 누끼에는 바닥, 그림자, 글로우를 넣지 않습니다. 백색 팩샷에는 요청이 없으면 약한 자연스러운 접지 그림자를 사용할 수 있습니다.

### 2. 레퍼런스 보드만

```text
이 제품에 맞는 프리미엄 스튜디오 촬영 레퍼런스 6장을 Behance와 Pinterest에서 찾아 이미지로 보여줘.
각 후보의 구도, 카메라, 조명, 배경, 색감, 소품을 설명하고 아직 생성은 하지 마.
```

### 3. 키비주얼 한 장

```text
이 제품의 형태와 패키지 문구를 보존해 4:5 마스터 키비주얼을 만들어줘.
브랜드 무드는 차갑고 미니멀한 프리미엄, 확산광, 밝은 회색 스튜디오, 우측 카피 여백으로 해줘.
```

키비주얼은 이후 상세페이지와 광고소재의 기준이 되는 팔레트, 조명, 표면, 소품 언어, 카피 여백과 크롭 안전영역을 정합니다.

### 4. 상세페이지 이미지

```text
승인된 키비주얼과 같은 캠페인 톤으로 상세페이지 이미지 5장을 만들어줘.
1) 히어로 2) 핵심 특징 3) 사용 장면 4) 소재 디테일 5) 마감과 CTA 순서로 구성하고 제품 형태와 라벨은 고정해줘.
```

상세페이지 전체 HTML이나 웹페이지가 아니라 요청한 이미지 모듈을 제작합니다. 모듈 수와 역할을 지정하면 불필요한 이미지를 추가하지 않습니다.

### 5. 프로모션 포스터와 광고소재

```text
다음 승인 문구를 한 글자도 바꾸지 말고 1:1 강조형 광고소재를 만들어줘.
메인: 여름 한정 20% OFF
서브: 8월 31일까지
CTA: 지금 구매하기
제품은 중앙, 헤드라인은 상단, CTA는 하단 안전영역에 배치해줘.
```

이미지 생성 모델이 정확한 타이포그래피를 보장하지 못하면 먼저 텍스트 없는 비주얼 플레이트를 만들고, 사용 가능한 레이아웃 도구로 승인 문구를 조판합니다. 조판 도구가 없으면 플레이트와 카피 배치도를 제공하고 텍스트 렌더링은 미완료로 표시합니다.

### 6. 채널별 광고 세트

```text
승인된 키비주얼을 기준으로 1:1 피드, 4:5 피드, 9:16 스토리, 16:9 배너를 만들어줘.
모든 규격에서 같은 제품 크기감, 조명, 팔레트와 CTA 체계를 유지하고 중요한 요소는 안전영역 안에 둬.
```

각 규격은 서로 다른 캠페인을 새로 생성하는 것이 아니라 승인된 마스터 방향에서 파생합니다.

### 7. 모델과 의류 착장

```text
첨부한 성인 모델의 얼굴, 머리, 체형을 고정하고 첨부한 원피스와 가방을 원본 구조와 색상 그대로 착장시켜줘.
3:4 전신 커머스 이미지, 자연스러운 정면 자세, 부드러운 스튜디오 조명으로 만들어줘.
```

모델과 의류·액세서리 원본은 각각 별도의 기준 이미지입니다. 의류 길이, 칼라, 소매, 솔기, 여밈, 패턴, 소재와 로고를 임의로 바꾸지 않습니다.

### 8. 부분 수정

```text
승인한 이미지에서 배경만 한 단계 더 밝게 해줘.
제품, 라벨, 구도, 크기, 조명 방향, 그림자와 모든 문구는 그대로 고정해줘.
```

부분 수정은 대상 영역과 한 가지 변화만 지정하는 것이 가장 안정적입니다. 짧게 `문구만 더 크게`, `그림자만 부드럽게`라고 말해도 언급하지 않은 승인 요소는 고정 대상으로 처리합니다.

### 9. 전체 커머스 이미지 세트

```text
이 원본으로 전체 커머스 이미지 세트를 만들어줘.
투명 누끼 1장, 백색 팩샷 1장, 마스터 키비주얼 1장, 상세페이지 모듈 5장, 1:1·4:5·9:16 광고소재 각 1장으로 구성해줘.
먼저 Behance·Pinterest 레퍼런스 6장을 이미지로 보여주고 내가 선택한 뒤 키비주얼을 승인받아 나머지를 파생해줘.
```

전체 세트에서는 키비주얼을 먼저 승인해야 이후 산출물의 캠페인 일관성을 유지하기 쉽습니다.

## 추천 제작 순서

### 빠른 단일 이미지

`원본 분석 → 필요 시 레퍼런스 → 생성 → 검수 → 전달`

### 전체 캠페인

`원본·문구 잠금 → 레퍼런스 선택 → 키비주얼 승인 → 상세페이지 파생 → 채널 광고 파생 → 전체 QA`

### 패션 세트

`모델 잠금 → 의류·액세서리 잠금 → 기준 착장샷 승인 → 포즈·크롭 파생 → 일관성 QA`

## 여섯 요소로 더 정확하게 요청하기

고급 사용자는 다음 여섯 요소를 한 번에 줄 수 있습니다.

1. **피사체:** 무엇을 어떤 상태로 보여줄지
2. **스타일과 무드:** 브랜드 인상, 시대감, 감정
3. **구도와 카메라:** 샷 크기, 각도, 렌즈감, 초점
4. **조명:** 방향, 광질, 대비, 색온도
5. **배경과 환경:** 장소, 표면, 소품, 색상
6. **출력:** 품질, 비율, 채널, 용도와 안전영역

복사해 쓸 수 있는 형식:

```text
피사체:
목적/채널:
비율/크기:
스타일/무드:
구도/카메라:
조명:
배경/소품:
승인 문구:
고정할 것:
수정 가능한 것:
레퍼런스 선택: 직접 선택 / 자동 선택 / 첨부 이미지 사용
```

## 원본과 레퍼런스의 역할

- 원본 사진: 제품·음식·모델·의류의 정체성과 승인 문구를 결정합니다.
- 레퍼런스: 구도, 카메라, 조명, 배경, 색감, 소품, 심도와 분위기만 결정합니다.
- 브랜드 자료: 로고, 컬러, 타이포그래피 계획과 표현 제한을 결정합니다.
- 승인 카피: 화면에 들어갈 정확한 문구와 계층을 결정합니다.

레퍼런스 속 다른 상품, 음식 구성, 모델 얼굴, 의상, 로고, 문구, 가격이나 브랜드 레이아웃을 복사하지 않습니다.

## 결과 검수 기준

최종 결과는 다음을 원본과 비교합니다.

- 제품 수량, 실루엣, 비율, 방향과 패키지 구조
- 재질, 색상, 투명도, 광택과 질감
- 로고, 라벨과 읽을 수 있는 원문
- 음식 재료, 모양과 경계
- 모델 얼굴, 머리, 체형과 피부 표현
- 의류 길이, 구조, 패턴, 색상, 소재와 액세서리
- 승인 문구, 숫자, 가격, 날짜, CTA와 줄 구분
- 요청 비율, 배치 안전영역과 채널 목적

치명적인 불일치가 있으면 결과를 승인하지 않고, 관찰된 문제만 명시해 한 번 보정합니다. 확인할 수 없는 부분은 정확하다고 주장하지 않습니다.

## 결과물 전달 내용

완료 시 다음 정보를 함께 받게 됩니다.

- 요청한 이미지 결과물
- 실제 적용한 비율과 레이아웃 유형
- 선택한 레퍼런스의 출처와 링크
- 정확한 문구 적용 상태
- 제품·모델·의류 보존 여부와 남은 한계
- 후속 부분 수정을 위한 간단한 제작 메모

새로운 아트 디렉션으로 다시 만들 때는 여러 번 수정된 결과보다 깨끗한 원본에서 다시 시작하는 것이 품질 보존에 유리합니다.
