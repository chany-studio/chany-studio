# Chany’s Studio 2.18 구현·검증 기준

작성·자료 확인: 2026-11-17. 출발 버전 2.17.0, 기준 커밋 `7734ac7`.

## 목적과 유지할 가치

사용자는 제품 사진 또는 서비스 자료와 원하는 레퍼런스만 제공한다. 레퍼런스가 없으면 스튜디오가 찾아서 보여준다. 사용자의 실제 상품·서비스를 지키면서 선택한 구도에 적용하고, 결과를 보고 필요한 부분만 고친다. 모델명·프롬프트·여러 제작 도구를 배울 필요가 없도록 한다.

## 구현 범위

- 버전별 복제 지침을 공통 계약으로 정리한다. 기존 작업에서 승인된 모델·자산·대사·사용자 변경을 보존한다.
- 레퍼런스 유지 삽입은 실제 사용 가능한 마스크/합성 도구가 픽셀 보존을 수행할 때와 생성형 근사 편집을 구분한다. 사용자가 소유/사용 허락한 템플릿은 편집 가능하고, 공개 검색 결과를 자동으로 재사용 허락으로 간주하지 않는다.
- 실제 이미지·모델 호출 대신 로컬 계획/제약 검사를 추가한다. 이는 입력 오류를 발견하는 장치이며 이미지 품질이나 실행 승인을 보장하지 않는다.
- 독립적인 모델별 스킬이나 Metricool 전용 스킬을 늘리지 않는다. 기존 제작·검색·성과 분석의 담당 경로를 확장한다.
- 발표된 기능과 현재 도구에서 실행 가능한 기능을 구분한다. GPU 대여, 베타 통합, 자동 게시를 기본 작업에 추가하지 않는다.

## 검증의 한계

유료 생성, 실제 인물/제품 파일 외부 전송, 광고 게시를 이번 개발 검증에 포함하지 않는다. 단위/회귀 검사는 실제 생성 품질 검증과 별도로 보고한다. 새 앱 세션에서 실행하지 못한 경로는 통과라고 적지 않는다.

## 사용자 자료와 개인정보

출처는 공개 URL과 요약으로 기록한다. 제3자 프롬프트·이미지를 배포물에 복제하지 않는다. 연결 계정 ID·이메일·성과 원자료·인증정보는 보고서와 공개 저장소에 포함하지 않는다.
