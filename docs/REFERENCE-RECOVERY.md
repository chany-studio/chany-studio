# 레퍼런스 검색 — 2.8.1

사이트를 지정하지 않으면 **Pinterest 5장 + Meigen 5장, 총 10장**을 대화에서 바로 비교합니다. 특정 사이트나 수량을 지정하면 그 요청이 우선합니다. Pinterest 단독·Meigen 단독은 기존 기본 6장 또는 요청 수량을 사용합니다.

검색어는 1차 카테고리와 직접 연결된 2차 하위 카테고리까지만 사용합니다. 이 범위에서 동의어·단복수 조정, 재검색, 페이지 이동과 후보 교체는 자동 진행합니다. 스타일·무드·카메라 같은 수식어를 추가하거나 더 깊은 분류로 내려가지 않습니다.

경로당 최대 6회 검색, 연속 2회 새 유효 후보가 없으면 중단합니다. 미리보기는 경로별 목표 수량의 최대 3배 후보까지만 시도합니다. 로그인·접근 제한·연결 실패는 우회하지 않습니다. 이미지를 못 보여주면 링크나 HTML로 완료했다고 안내하지 않습니다.

부족하면 확보한 이미지를 먼저 보여주고 요청 수·표시 수·부족 수와 원인을 안내합니다. “추가 검색 허용”을 요구하지 않으며 확보분으로 진행·직접 레퍼런스 제공·외부 레퍼런스 없이 제품 분석으로 진행 중 한 번만 선택하도록 합니다.

## 복사해서 사용하기

> 프로젝트 폴더의 제품사진을 분석하고 Pinterest 5장과 Meigen 5장, 총 10개의 레퍼런스를 이 대화에 이미지로 바로 보여줘. 1차·직접 2차 카테고리 안의 재검색과 후보 교체는 자동 진행해줘. 추천 방향과 실제 이미지 생성 모델·비율·장수·비용, 필요한 외부 업로드를 한 번에 정리해서 승인받아줘. Meigen 원본 프롬프트가 공개돼 있으면 함께 분석해줘.

사진 원본과 승인 카피, GPT Image 2.5 기본값은 유지합니다. 요청한 4:5가 실제 도구에서 3:4로 바뀌면 조용히 진행하지 않고 그 차이를 같은 승인안에서 알려야 합니다.
