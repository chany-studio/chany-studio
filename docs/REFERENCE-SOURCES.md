일반 사진 레퍼런스는 **Pinterest 6장**이 기본입니다. 일반 영상 후보는 **3개**, Meta 광고와 광고 사례 전용 검색은 **6개**가 기본이며, 원하는 수량을 말하면 그 요청을 따릅니다. 여섯 사이트를 매번 전부 검색하지 않습니다.

사이트를 직접 고를 필요 없이 “내 제품에 맞는 참고 영상도 찾아줘”라고 시작할 수 있습니다. 직접 준 사진이나 영상이 있으면 먼저 분석하고 불필요한 새 검색은 생략합니다.

## 줄인 범위

외부 AI 갤러리 전용 기능과 혼합 사진 보드를 제거했습니다. 중복 광고 아카이브, 패키지·UI·공간·폰트·색상 사이트, 추천 인스타그램 계정의 긴 목록은 기본 검색처에서 제외했습니다. 기존 광고 사례 호출 이름은 저장한 요청과 호환되도록 유지하며 검색처는 Ads of the World로 좁혔습니다. 수상 여부는 실제 출처에서 확인된 경우에만 말합니다.

사용자가 직접 준 Instagram·YouTube·TikTok 영상, 다른 사이트나 노션 자료는 계속 분석할 수 있습니다. 명시적으로 지정한 외부 사이트는 별도 검색 대상으로 다루되 기본 목록을 늘리지 않습니다. Metricool은 설정된 경쟁 계정 분석이 필요할 때만 사용하는 선택 기능입니다.

## 확인 범위

사이트 등록은 자동 연결·열람·미리보기 성공을 뜻하지 않습니다. 로그인이나 접근 제한이 있으면 확인한 범위와 부족한 후보 수를 알려드립니다. 영상 썸네일만 보고 움직임·음악을 분석했다고 하지 않습니다. 실제 매출 성과는 공개 광고·좋아요·수상 여부로 단정하지 않습니다.

2.20.0 배포 후보에는 직전 영상 중심 인터뷰 보완도 포함됩니다. 실제 생성 비용은 제작 직전 확인하며, 이번 검색처 정리는 유료 영상 생성이나 공개 게시 승인이 아닙니다.
