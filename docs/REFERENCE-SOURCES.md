# 레퍼런스 검색처 — 2.21.0

처음부터 많은 사이트를 고르게 하지 않습니다. 만들 결과에 맞는 한 곳부터 시작하고, 필요할 때만 두 곳까지 비교합니다.

| 만들 것 | 먼저 찾는 곳 | 사용하는 이유 |
|---|---|---|
| 사진의 구도·빛·배경 | [Behance](https://www.behance.net/) | 제품에 어울리는 촬영 방향 찾기 |
| 전문 광고·제품 사진 | [Production Paradise](https://www.productionparadise.com/) | 상업사진의 완성도와 제품 표현 비교 |
| 광고 아이디어·릴스·이미지·캐러셀 | [Instagram](https://www.instagram.com/) **우선** | 실제 게시물의 첫 장면·제품 표현·전개 참고 |
| 광고 집행 사례·추가 비교 | [Meta 광고 라이브러리](https://www.facebook.com/ads/library/) **보조** | 광고로 확인되는 소재와 문구·행동 유도 방식 비교 |

| 모션그래픽·애니메이션 | [Motionographer](https://motionographer.com/) | 움직이는 글자·그래픽·애니메이션 참고 |

일반 사진 레퍼런스는 **Behance 6장**이 기본입니다. 인스타그램 중심 광고 후보는 Meta 보충분까지 합쳐 **3개**, 일반 영상 후보도 **3개**가 기본입니다. Meta만 지정하거나 Ads of the World를 명시한 전용 검색은 **6개**가 기본이며, 원하는 수량을 말하면 그 요청을 따릅니다. 여섯 사이트를 매번 전부 검색하지 않습니다.

사이트를 직접 고를 필요 없이 “내 제품에 맞는 참고 영상도 찾아줘”라고 시작할 수 있습니다. 직접 준 사진이나 영상이 있으면 먼저 분석하고 불필요한 새 검색은 생략합니다.

## 내 제품에 맞는 인기 릴스

Apify는 인스타그램을 검색하는 연결 도구입니다. 검색처 여섯 곳은 그대로 유지합니다. 제품 설명으로 키워드를 만들고, 제품 적합도를 먼저 따진 뒤 실제 재생수·좋아요와 확인 가능한 공유수로 총 3개를 추천합니다.

2026-11-17 무료 계정 실검증에서는 키워드 검색 12개와 추가 조회 6개가 성공했습니다. 공유수는 무료 계정에서 지원되지 않는다는 실행 경고를 확인했습니다. 조회수와 재생수는 구분하고, 오래된 인기 사례를 최신으로 표시하지 않습니다. [검증 결과·사용법](APIFY-INSTAGRAM-VERIFICATION.md)

## 줄인 범위

외부 AI 갤러리 전용 기능과 혼합 사진 보드를 제거했습니다. 중복 광고 아카이브, 패키지·UI·공간·폰트·색상 사이트, 추천 인스타그램 계정의 긴 목록은 기본 검색처에서 제외했습니다. Ads of the World도 기본 검색처에서는 제외했습니다. 해당 사이트를 명시하거나 기존 전용 호출을 사용하면 계속 분석할 수 있습니다. 수상 여부는 실제 출처에서 확인된 경우에만 말합니다.

사용자가 직접 준 Instagram·YouTube·TikTok 영상, 다른 사이트나 노션 자료는 계속 분석할 수 있습니다. 명시적으로 지정한 외부 사이트는 별도 검색 대상으로 다루되 기본 목록을 늘리지 않습니다. Metricool은 설정된 경쟁 계정 분석이 필요할 때만 사용하는 선택 기능입니다.

## 확인 범위

사이트 등록은 자동 연결·열람·미리보기 성공을 뜻하지 않습니다. 로그인이나 접근 제한이 있으면 확인한 범위와 부족한 후보 수를 알려드립니다. 영상 썸네일만 보고 움직임·음악을 분석했다고 하지 않습니다. 실제 매출 성과는 공개 광고·좋아요·수상 여부로 단정하지 않습니다.

인스타그램 일반 게시물·협찬 표시·Meta에서 확인한 광고는 구분합니다. 인스타 접근이 막히면 확인하지 못한 범위를 알리고 Meta 보조 검색으로 이어갑니다. 인스타만 요청했다면 임의로 다른 출처로 채우지 않습니다. 실제 생성 비용은 제작 직전 확인하며, 이번 검색처 정리는 유료 영상 생성이나 공개 게시 승인이 아닙니다.
