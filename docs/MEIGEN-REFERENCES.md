# Meigen 이미지·프롬프트 레퍼런스 · 2.7.0

`chany-ai-prompt-reference`는 Meigen의 AI 이미지와 공개된 원본 프롬프트를 함께 분석해 내 제품·서비스에 맞는 제작 프롬프트로 바꿉니다.

## 용도와 흐름

- 제품 연출컷의 조명·구도·재질을 프롬프트와 함께 분석
- 광고·포스터·캐러셀의 시각 표현 구체화
- 내 제품 원본·브랜드·승인 문구를 보존하는 제작 프롬프트 작성

Pinterest는 사진의 미학, Meigen은 AI 이미지와 프롬프트, Meta 광고 라이브러리는 실제 집행 광고의 훅·카피·CTA 분석에 사용합니다. 구매 전환 작업에서는 JTBD·Meta 분석으로 메시지를 정한 뒤 필요할 때 Meigen을 연결합니다.

## 검색과 결과

기본 6장, 요청한 수량이 있으면 해당 장수를 목표로 합니다. 업종 L1 영어 키워드 하나와 필요할 때 직접 L2 하위 키워드 하나까지만 검색합니다. 분위기·색·조명·트렌드는 선별과 제작 프롬프트에 반영합니다.

이미지를 현재 대화에 직접 표시하고 출처·작성자·원본 모델·검색어·프롬프트 공개 여부를 기록합니다. 원본 프롬프트 핵심과 새 제작 프롬프트를 구분합니다. 프롬프트 미공개나 이미지 표시 실패로 부족하면 요청·표시·부족 수량을 알리며 다른 사이트로 보충하지 않습니다.

GPT Image 2 (`gpt-image-2`) 기본값은 유지됩니다. 좋아요·조회수는 구매·CPA·ROAS의 증거가 아닙니다. 원본 이미지의 공개는 상업적 재사용 허락을 의미하지 않습니다.

## 복사해서 쓰는 프롬프트

### 제품 연출 레퍼런스

> @chany-ai-prompt-reference로 첨부 제품에 맞는 Meigen 이미지와 원본 프롬프트 6개를 찾아줘. 업종 1차 키워드와 필요할 때 직접 2차 키워드까지만 검색하고 이미지를 대화에 직접 보여줘. 각 이미지의 구도·조명·재질과 원본 프롬프트 핵심을 설명하고, 선택 후 내 제품을 보존하는 GPT Image 2 제작 프롬프트로 바꿔줘.

### 수량 지정

> @chany-ai-prompt-reference로 이 카페 음료의 Meigen 레퍼런스 9장을 보여줘. 이미지와 공개 프롬프트가 함께 확인되는 후보만 사용하고, 부족하면 요청 수·표시 수·부족 수를 알려줘.

### 캐러셀 제작 연결

### 프로젝트 초기화

> /project-studio 신제품의 Meigen 레퍼런스와 4:5 광고 이미지 프로젝트를 설정해줘. chany-ai-prompt-reference를 필요한 검색 단계에 연결하고 제품 원본과 승인 카피를 보존해줘. 설정 중에는 검색·생성을 시작하지 마.

ChatGPT Work에서는 `@chany-ai-prompt-reference`, Codex에서는 `$chany-ai-prompt-reference`, Claude Cowork에서는 같은 요청을 자연어로 입력합니다. `/project-studio`는 Claude 프로젝트 초기화 명령입니다.

## 연결과 이미지 표시

Meigen MCP는 자동 설치되지 않습니다. 이미 연결된 `search_gallery`·`get_inspiration`이 있으면 사용하고, 없으면 공개 Meigen 페이지를 검색할 수 있는 브라우저와 이미지 표시 기능을 사용합니다. 둘 다 없으면 접근 가능한 이미지와 프롬프트를 제공받아 분석합니다.

Pinterest 전용 `reference-preview`에 Meigen 주소를 넣지 않습니다. 링크나 HTML만 제공된 상태는 이미지 보드 완료가 아닙니다. 오프라인 라이브러리는 최신성 미확인으로 표시합니다. Meigen 영상은 실제 영상이 관찰 가능한 경우에 기존 영상 분석 스킬로 연결합니다.
