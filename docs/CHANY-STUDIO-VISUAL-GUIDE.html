사진과 영상, 여기만 달라요

실제로 필요한 제작 단계만 확인해요.

새 이미지와 영상이 모두 필요하면 각 유료 단계를 확인해요. 이미 승인한 기준 이미지는 재사용하고, 기존 영상의 배경·조명·부분 편집에 새 이미지를 무조건 만들지 않아요. 참고 사진이 충분하면 검색도 반복하지 않아요.

이미지 제작

  1. 사진·설명·목적 전달
  2. 첨부 참고 사진 우선, 필요하면 레퍼런스 추천
  3. 내 확인: 방향·문구·입력 전송·수량·비용
  4. 이미지 생성 → 제품·라벨 검수

새 영상 제작

  1. 제품·영상 아이디어 전달
  2. 기준 이미지가 없으면 방향·전송·생성 비용 확인
  3. 이미지를 만들고 검수, 승인한 이미지가 있으면 재사용
  4. 영상 확인: 기준 이미지·길이·전송·생성 비용
  5. 클립 생성 → 전체 재생·소리 검수 → 최종 조립
