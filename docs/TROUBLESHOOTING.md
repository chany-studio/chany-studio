# 문제 해결

[공식 설치·사용설명서 (Notion)](https://jolly-phlox-79c.notion.site/AI-Photo-Reference-Studio-v1-0-3c783e9464668140b794ee076be24406)

## 마켓플레이스 추가 버튼이 보이지 않음

- 현재 플랜, 워크스페이스 역할과 지원 화면에서 커스텀 플러그인 마켓플레이스를 사용할 수 있는지 확인합니다.
- 관리형 ChatGPT 워크스페이스에서는 관리자 또는 소유자가 플러그인 설치 정책과 포함 앱 접근을 허용해야 할 수 있습니다.
- Claude에서는 개인 Git 저장소 마켓플레이스가 Cowork와 Claude Code에 지원됩니다. 사용하는 화면이 Claude Chat만이라면 Cowork의 Customize 메뉴에서 설치를 진행합니다.

## 저장소를 추가했지만 플러그인이 안 보임

1. 저장소 주소가 정확한지 확인합니다.

```text
https://github.com/junphoto1008-tech/photo-reference-studio
```

2. 마켓플레이스 이름 `photo-reference-studio`를 찾아 Refresh 또는 Update를 누릅니다.
3. 앱을 다시 시작하고 Plugins 목록을 다시 엽니다.
4. 관리형 워크스페이스라면 설치 정책과 사용자 역할을 확인합니다.
5. Claude Code에서는 `/plugin`의 Errors 탭을 확인합니다.

## 업데이트했는데 예전 기능이 나옴

다음 증상은 이전 설치본일 가능성이 높습니다.

- 버전이 `1.3.2`보다 낮음
- 레퍼런스 소스로 Behance와 Pinterest 이외의 사이트를 안내함
- 레퍼런스를 이미지가 아닌 링크 목록만 제공함
- 키비주얼 외 상세페이지·광고소재 작업을 지원하지 않는다고 안내함

플랫폼의 Refresh 또는 Update를 실행하고 플러그인 버전을 확인한 뒤 반드시 새 대화나 새 작업을 시작하세요. 열린 대화는 시작 시 로드한 이전 지침을 계속 사용할 수 있습니다.

## Higgsfield 연결 요청이 반복됨

- 앱이나 Claude/Codex가 표시하는 연결 또는 로그인 버튼을 사용합니다.
- 인증을 마친 뒤 처음 작업하던 대화로 돌아옵니다.
- 브라우저와 데스크톱 앱의 로그인 계정이 동일한지 확인합니다.
- 관리형 워크스페이스에서는 Higgsfield 연결이 해당 역할에 허용되었는지 관리자에게 확인합니다.
- 비밀번호, API 키, 액세스 토큰이나 인증 코드를 채팅에 붙여 넣지 않습니다.

Higgsfield 사용 권한, 요금제와 생성 크레딧은 이 플러그인에 포함되지 않습니다.

## 레퍼런스 이미지가 대화에 표시되지 않음

플러그인의 최종 레퍼런스 보드는 링크나 HTML만 제공하면 안 됩니다. 먼저 플러그인 상세에서 `reference-preview` 연결이 활성화되어 있는지 확인한 다음 새 Cowork 작업에서 다시 실행하세요. 정상 동작에서는 여섯 후보가 현재 대화 안의 실제 이미지로 먼저 보이고, 원문 링크는 각 이미지 아래에 붙습니다.

`reference-preview` 연결 자체가 시작되지 않으면 터미널에서 `node --version`을 확인합니다. `v18` 이상이 표시되지 않거나 명령을 찾을 수 없다면 [Node.js LTS](https://nodejs.org/en/download)를 설치하고 Claude Desktop을 완전히 종료했다가 다시 엽니다. 이 연결은 npm 패키지를 추가로 설치하지 않습니다.

필요하면 다음처럼 요청하세요.

```text
링크나 HTML만 주지 말고 `reference-preview`를 사용해 Behance·Pinterest 후보 6장을 현재 대화 안의 실제 이미지로 다시 보여줘. 표시되지 않는 후보는 교체해줘.
```

일부 페이지는 외부 이미지 표시를 차단하거나 임시 URL을 사용할 수 있습니다. `reference-preview`가 공개 미리보기 바이트를 가져오지 못하면 해당 후보를 검증 가능한 다른 후보로 교체해야 합니다. 원문 링크와 선택적 HTML 보드는 출처 확인용 보조물이며 직접 표시를 대신하지 않습니다.

연결이 보이지 않으면 마켓플레이스를 Update하고 플러그인을 다시 연 뒤 새 Cowork 작업을 시작합니다. 그래도 실패하면 플러그인 버전, `reference-preview` 연결 상태와 개인정보를 제거한 오류 메시지를 버그 제보에 포함하세요.

## Pinterest 또는 Behance 외 사이트가 나옴

다음처럼 정책을 명시해 다시 요청합니다.

```text
레퍼런스는 Behance와 Pinterest 공개 페이지만 사용하고 다른 사이트 후보는 모두 제외해줘.
```

계속 다른 소스가 나오면 설치 버전을 확인하세요. 최신 버전에서 허용된 레퍼런스 소스는 Behance와 Pinterest뿐입니다.

## 제품 라벨·형태·음식·의류가 변형됨

해당 결과를 승인하지 말고 원본 사진을 다시 기준으로 지정합니다.

```text
원본을 다시 권위 이미지로 사용해 제품 실루엣, 라벨, 재질과 색상을 복구해줘.
현재 구도와 조명은 유지하고 관찰된 변형만 수정해줘.
```

투명 누끼는 생성형 재그리기보다 배경 제거를 우선해야 합니다. 새 아트 디렉션을 시도할 때는 여러 번 수정한 결과가 아니라 깨끗한 원본에서 다시 시작합니다.

## 광고 문구가 틀림

정확한 문구를 텍스트로 다시 제공하고 `copy_lock`으로 고정하도록 요청합니다.

```text
승인 문구는 아래와 같아. 한 글자도 바꾸지 말고 줄 구분도 유지해줘.
메인: ...
서브: ...
CTA: ...
```

이미지 생성 모델만으로 정확한 문구가 어려우면 텍스트 없는 비주얼 플레이트와 카피 배치도를 먼저 받고 레이아웃 도구로 조판합니다.

## 부분 수정이 전체 이미지를 바꿈

한 번에 한 가지 속성만 요청하고 바꾸지 않을 항목을 명시합니다.

```text
배경 밝기만 수정해줘. 제품, 문구, 구도, 크기, 조명 방향과 그림자는 모두 고정해줘.
```

지원되는 경우 마스크 또는 명확한 영역 설명을 함께 제공합니다.

## 생성이 시작되지 않음

기본 `semi-auto` 모드에서는 레퍼런스 후보를 보여준 뒤 사용자의 선택을 기다립니다. `1`부터 `6` 중 하나를 답하거나 `자동 선택`이라고 입력하세요.

Higgsfield 도구가 연결되지 않은 경우 플러그인은 분석, 프롬프트와 레이아웃 계획까지만 제공할 수 있습니다. 이때는 연결 상태를 해결한 뒤 중단된 생성 단계부터 다시 진행합니다.
