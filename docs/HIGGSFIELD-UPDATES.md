## 광고 모션 디자인

> 이 승인된 광고 이미지로 10초 모션 광고를 만들어줘. 제품은 그대로 두고 훅 문구와 마지막 CTA만 절제된 움직임으로 강조해줘. Higgsfield 연결 가능 여부부터 확인해줘.

정확한 카피·읽는 시간·안전 영역·브랜드 모션을 설계합니다. Higgsfield의 실제 실행 연결이 없으면 기획안까지만 제공하며 영상 생성 완료로 안내하지 않습니다. 편집 가능한 AE 프로젝트가 필요한 경우 해당 연결과 출력 능력을 별도로 확인합니다.

## Genjutsu 영상 부분 수정

> 우리가 제작한 이 제품 영상에서 병만 첨부한 새 패키지로 교체해줘. 카메라와 배경, 길이와 소리는 유지하고, 라벨과 손이 겹치는 구간을 특히 검수해줘. 생성 전 비용과 변경 범위를 보여줘.

> 사용 권한이 있는 이 영상의 움직임을 새 제품 장면에 적용해줘. 브랜드와 구성은 우리 제품에 맞게 새로 만들고 제품 형태를 검수해줘.

기존 `chany-campaign-video`의 수정 모드입니다. 원본과 결과를 비교하고 승인된 결과만 편집에 넘깁니다. 공개 광고를 볼 수 있다는 이유만으로 복제·변환 권한이 있다고 보지 않습니다. 보존 요청은 검수 기준이지 성공 보장이 아닙니다.
