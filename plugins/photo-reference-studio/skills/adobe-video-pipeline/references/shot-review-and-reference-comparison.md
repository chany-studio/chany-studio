# Shot review and reference comparison

Use when an approved excerpt must become a coherent longer film or when the user specifies an ambitious quality reference. Keep the selected visual direction. A higher target does not authorize a new art style, renderer, soundtrack or paid platform.

## Convert a reference into observable choices

Inspect more than one relevant passage when judging a creator's range. Compare like with like: opening to opening, explanation to explanation, character dialogue to dialogue. Record source URL/timecode, what was actually seen, and whether full-speed sound was available. A title, search snippet or contact sheet is not evidence of a complete video review.

Compare audience comprehension, staging, performance, graphic hierarchy, material consistency, transitions and rhythm separately. Name a concrete defect and a correction: for example, three simultaneous focal movements, a read interval ending before the caption, or a face seam at a head turn. Avoid unsupported numerical quality scores or a blanket claim of reference superiority.

Borrow methods and analyze decisions; create original shot designs within the approved look. Rights to view a film do not grant rights to its source project, character art, footage or typography assets.

## Run shot reviews with a recoverable baseline

Record `shot_id`, current edit range, source picture/audio revisions, viewer question, focal subject, exact defect/time, proposed change, preserved decisions and proof required. Review the shot with its neighbors. One note should lead to one testable correction, not an uncontrolled whole-frame redesign.

Use these review areas as needed:

| Area | Useful proof | Frequent false positive |
|---|---|---|
| Story/evidence | Picture answers the spoken question at the right moment | Visually impressive but unrelated montage |
| Acting | Intention, eyeline, reaction and supported body weight at 1× | A mouth that moves but has no convincing performance |
| Graphics | Final-size type and evidence readable during the hold | Attractive enlarged still only |
| Material/composite | Stable grain, coherent shadow, clean joins through motion | A single clean alpha frame |
| Edit | Necessary cut/hold, clear focal handoff, complete sound tails | An arbitrary target duration or repeated transition |
| Delivery | Reopened native project and verified final encode | A saved XML or completed render log alone |

For performance detail, use the AE skill's dialogue-staging reference. For source images, use the image skill's look-development reference. For encoded sync and editorial passes, use the Premiere skill's export-sync reference if those skills are available; otherwise apply the criteria directly without claiming those tools were executed.

## Evidence states

Record source documentation, asset inspection, native shot test, editorial review and user acceptance independently. They are not interchangeable stages in an automatic approval ladder. A test can pass technically while failing art direction.

Keep unresolved defects specific and prioritized. A missing source, inaccurate map, changed identity, unreadable key fact or broken sync takes precedence over decorative depth. Continue independent shots while a known external asset is pending; preserve an explicitly requested placeholder rather than inventing its contents.

Apply accepted changes across every affected occurrence in the full film. Audit nested comps and source substitutions; an excerpt may only reach a fraction of the project. When timing changes, reconform all affected stems, captions and markers together. Do not use a historical full render as proof of a newer excerpt's changes.

## Transfer methods, not private project evidence

For a representative-cut test, preserve the accepted composition while correcting local mouth keys; keep source credits readable; remove rejected dialogue across all tracks; preserve independent audio stems; and measure encoded audio timing against the current PCM mix. Select only the operations the current job needs.

These checks are procedures, not claims that this host has executed them. Re-measure export delay for every changed route and review each new line. Keep authors, source URLs, inspection limits and trial artifacts in the current project's evidence register. Skill installation proves instruction availability; only actual output demonstrates quality.
