## A useful trial has a pass condition

| Trial | Required comparison |
|---|---|
| Material-aware paper | Rest/lift/settle with coherent contact, anchored texture and no content distortion |
| Articulated dialogue | Same WAV with local jaw/cheek motion, varied intent/listening poses, stable face identity and closures |
| Evidence-focused map | Overall location → one exact feature → readable original detail; no geography invented |
| Eye-trace transition | Same information with outgoing/incoming focal continuity and usable reading holds |
| Source montage | Same real footage with action roles, no unsupported causal implication, and purposeful sound/quiet |
| Native CG | One isolated sample, actual renderer/version/color/alpha checked before wider use |

Write project-specific parameters in the project's trial plan rather than making them universal skill rules. Keep future experiments separate from an already validated build. Promote a documented method to locally tested only after saving and reviewing its actual native render, and to production accepted only after editorial-context review.
