# Native production verification

Use this as a local trial procedure, not a record of a prior client's production. No source film, map, voice, project file or third-party template is bundled.

## Establish the native route

1. Inspect the installed AE and Premiere versions and available execution tools. Author editable AE comps with a locally created JSX or supported UI/API route. Preserve authoritative supplied maps, logos and copy.
2. Save a new AEP and render with the installed render queue or `aerender`. Inspect output-module names; localization and filename extensions do not establish the codec. Measure the actual output.
3. Import into Premiere using a supported native route or a frame-accurate interchange file. Preserve scene cuts and independent dialogue/music/effects. Save a native PRPROJ, close and reopen it to verify media linking. XML alone is not a native project delivery.
4. Export from Premiere and inspect the actual encoded duration, dimensions, frame cadence, audio presence, sync and loudness. Verify color and alpha where applicable.

## Templates and plugins

Check the original creator's distribution and exact package license. A MOGRT may contain an AE graphic/project, but do not assume all packages expose editable source. When adapting typography, inspect both entrance animation and settled text: masks, anchors and Latin metrics can clip Korean copy.

A plugin window appearing proves launch only. Record installation, compatibility and functional use separately. Do not weaken script/security preferences or buy a paid extension just because a tutorial uses it. No external extension is a dependency of these skills.

## Final audio and UI proof

Per-source normalization does not establish final true peak: imported mono/stereo routing and encoding can change the mix. Measure the final export and preserve independent stems. Meter readings do not substitute for listening.

A custom app field can ignore a successful setter call. Inspect visible values and the resulting file after changes. Use the location chooser for directories and the filename field for names. A successful click, script return or render exit code is not proof of a correct output.

Keep paths, versions, logs, measurements, reviewed frames and unresolved listening/creative checks in the current project. Do not copy another project's completion status.
