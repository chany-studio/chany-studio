# Recut acceptance

For each candidate record source time range, complete thought, hook, claim/qualification integrity, crop, speaker continuity, transcript, subtitle line breaks, brand fit, CTA, duplicate status, and publication status.

Reject a clip when the edit changes meaning, removes a material qualification, creates a false endorsement, clips a price/date/unit, exposes unapproved personal data, or makes subtitles unreadable at expected mobile size.
