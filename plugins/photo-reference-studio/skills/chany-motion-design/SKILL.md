# Chany Motion Design

Turn approved advertising assets and copy into readable, brand-specific motion. A standalone motion card stays with this skill; a full commercial keeps `chany-campaign-video` as owner and calls this skill only for named graphics. Do not introduce motion into a static-image or carousel request.

Read the shared [Higgsfield motion adapter](../chany-studio/references/higgsfield-motion-adapter.md) before choosing an execution route. Use its observed capability gate in Claude and ChatGPT Work/Codex alike; an advertised integration is not an available connection.

## Design and execution

1. Reuse the approved brief, exact copy version, product/brand source assets and requested placement. Confirm only missing duration, aspect ratio and editable-source requirements. Never invent prices, benefits or urgency.
2. Create one compact motion packet: `motion_packet_id`, parent asset/version, approved copy version, target, layer list, cue timings, animation properties, locked regions and acceptance checks. Each cue has a message job: hook, proof, offer or CTA. A reference contributes general rhythm, not copied distinctive animation or branding; video references use `chany-video-reference-ingest`.
3. Keep the product authority unchanged. Prefer editable text/vector layers for exact Korean copy and prices. Limit simultaneous emphasis, use a consistent easing family and intentional holds, and test actual reading time at mobile size. Choose restrained or expressive motion to fit the brand, not a universal preset. Keep CTA/disclosures visible long enough to read and inside current placement safe zones.
4. Approve a layout frame and timing plan before rendering. Preview at the requested ratio; animated text must not cover the product, evidence or disclosures. Read the shared [platform adapter](../chany-studio/references/platform-publication-adapter.md) for named placements.
5. Execute only the verified Higgsfield route from the adapter. Preserve the original project and render a new version; obtain approval before overwriting user work. Generated source plates/clips use `chany-media-production-loop` and its image-model and cost rules. Native composition edits remain this skill's responsibility, not imaginary generation jobs.
6. Inspect the rendered motion, not only a still: font fallback, line breaks, clipping, entry/exit frames, reading holds, flashing, continuity and final CTA. Keep text accurate when paused and understandable without sound. Allow one initial render and at most one defect-specific correction within the approved scope; further paid attempts require new approval.
7. Return the actual preview, verified output file and editable project only when created, with source/version, unresolved defects and capability status. For inclusion in a film, hand the accepted graphics, timing/alpha requirements and copy version to `chany-video-assembly`. Apply `chany-publication-review` when required; creative approval is not publication authority.

If no suitable execution route exists, deliver the completed motion packet and tool-ready instructions marked **plan-only**. Do not call it a rendered video or claim an editable After Effects project exists.
