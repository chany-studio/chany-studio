# 이야기 개발과 시리즈 설계

## 문서의 역할

짧은 작품은 아래 항목을 한 문서에 합쳐도 된다. 문서 수보다 결정의 선후 관계를 지킨다.

| 문서 | 담아야 하는 결정 |
|---|---|
| 제작 브리프 | 관객, 경험·행동 목표, 형식·길이, 예산·공개 범위 |
| 로그라인·기획의도 | 누가 무엇을 원하지만 무엇 때문에 곤란해지는지 |
| 시리즈 바이블 | 욕구·결핍·관계, 세계의 규칙, 반복 가능한 갈등, 시즌 변화 |
| 시놉시스 | 시작부터 결말까지 선택과 결과의 인과 |
| 트리트먼트·비트시트 | 장면별 사건, 감정 변화, 정보의 공개 순서 |
| 대본 | 장소·시간, 관찰 가능한 행동, 대사·침묵·소리 |
| 연출안·콘티·숏리스트 | 관객에게 언제 무엇을 어떻게 보여줄지 |

‘시나리오’와 ‘대본’을 반드시 별도 문서로 만들지 않는다. 작품마다 명칭이 다르므로 이 작업에서의 용도를 정의한다. 숏리스트는 컷 제작 목록, 콘티는 화면과 연결의 시각 설계다.

## 인과와 연기

장면마다 `욕구 → 저항 → 구체적인 시도 → 결과 → 다음 선택`을 적는다. 이유 없이 이어지는 장면은 생성 전에 고친다. 모든 작품을 정해진 3막 비율에 맞추지는 않는다.

장면 전후에 관계·정보·주도권 중 하나가 달라지는지 본다. 설명 대사는 반응이나 행동으로 바꿀 수 있는지 검토한다. 숨은 의도는 배우가 실행할 동사로 쓴다. ‘불안하다’ 대신 ‘자료 모서리를 맞추며 시간을 번다’처럼 상황에 맞게 고른다. 모든 인물에게 같은 버릇을 주지 않는다.

코미디는 인물의 진심을 유지한다. 정상적인 기대를 만들고 어긋나는 행동을 정확한 시점에 보여준다. 웃음을 설명 자막으로 다시 풀이하지 않는다. 타이밍은 낭독과 임시 편집으로 찾는다. 모든 순간을 빠르게 자르지 않는다.

시리즈는 회차의 문제를 해결하면서 관계 변화나 다음 질문을 남긴다. 같은 제품 설명을 반복하지 않는다. 인물의 지식·관계·시간·소품이 바뀌면 바이블에 갱신 근거를 남긴다.

## 브랜드 드라마

한 편의 사업 메시지는 하나부터 설계한다. 공감할 문제와 실제 제공 범위를 연결하고 해결 이후 인물의 행동이 어떻게 달라지는지 보여준다. 설명을 제거해도 사건이 살아 있는지, 반대로 이야기를 보고도 서비스 역할을 알 수 없는지 모두 점검한다.

주장표는 `대사/화면`, `근거`, `확인자·날짜`, `허용 범위`, `보류 표현`을 담는다. 사용자 확인·공개 페이지·계약 문서·기획 가정을 구별한다. 무료·보장·순위·기간·매출은 근거 없이 추가하지 않는다.

## 저비용 검증

직접 낭독하거나 승인된 임시 음성으로 시간을 잰다. 발화뿐 아니라 이해·시선 이동·동작·웃음의 여백을 포함한다. 콘티에 음성을 얹어 임시 편집한다. 미제작 그림은 자리표시자로 남겨도 된다.

검토자가 실제 있다면 ‘무엇을 원했나’, ‘무슨 일이 바뀌었나’, ‘어디서 헷갈렸나’를 묻고 답변 그대로 기록한다. 혼자 검토했다면 시청자 검증 완료라고 쓰지 않는다. 이탈률·전환율 개선을 실측 없이 주장하지 않는다. 다음 단계에는 대본 버전, 측정/가정 러닝타임, 감정 변화와 수정 사유를 넘긴다.
