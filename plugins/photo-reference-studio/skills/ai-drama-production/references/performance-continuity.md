# 연기·블로킹·연속성

상대와 주고받는 연기는 [대화·연기 수정](acting-dialogue.md), 공간·동작 참조의 선택은 [블로킹 지침](blocking-motion.md)에 구체화돼 있다. 필요한 항목만 추가로 읽는다.

## 기준 자산과 공간

인물별 얼굴, 측면·전신, 의상·신발, 키·체형 관계, 목소리·말버릇을 버전으로 묶는다. 승인 원본과 장면 파생 이미지를 구별한다. 참조를 많이 넣는 것 자체가 품질을 높이지 않는다. 참조마다 역할을 명시하고 상충하는 사진은 제거한다.

공간은 평면도부터 만든다. 문·창문·책상·광원, 인물과 시선, 카메라 위치를 기록한다. 두 사람의 화면 좌우와 대화축을 정한다. 축을 넘을 때에는 이동을 보여주거나 중립 구도 등 관객이 위치를 다시 파악할 장치를 둔다. 축을 절대로 넘지 말라는 규칙으로 쓰지 않는다.

| 기록 항목 | 예 |
|---|---|
| 정체성 | 얼굴·머리·의상 원본 경로와 버전 |
| 공간 | 카메라 A, 화면 왼쪽 인물, 화면 오른쪽을 보는 시선 |
| 소품 | 오른손 펜 → 책상에 놓음 → 다음 컷 책상 오른편 |
| 동작 | 서 있음 → 의자 당김 → 앉음 |
| 빛·소리 | 창문 방향·색, 방의 잔향, 화자 ID |
| 감정 | 숨기려는 것, 상대에게 원하는 것, 직전 반응 |

## 연기 지시

시작 상태, 주 행동, 끝 상태와 듣는 사람의 반응을 적는다. 시선의 대상·전환 시점, 실제 접촉, 호흡·망설임을 선택한다. 감정을 신체 신호 목록으로 과하게 분해해 기계적 연기를 만들지 않는다. 듣는 표정도 상대의 말 때문에 결정이 바뀌는 순간이다. 미소를 장면 전체에 붙여두지 않는다.

다인 대화 제어가 검증되지 않았으면 화자별 컷·반응·어깨너머 구도·소품 삽입을 설계한다. 시선·거리·목소리·음향 공간은 연결돼야 한다. 두 사람의 몸짓이 핵심이면 분할 때문에 연기를 잃는지 검토한다. 도구가 지원하면 작은 시험으로 다인 대화를 검증한다. 장면 의미보다 모델 편의만 우선하지 않는다.

## 기준 이미지와 영상

콘티는 정보·위치·행동·연결 확인용, 키프레임은 생성 외형·구도 고정용이다. 최초 프레임의 관계나 행동이 불가능하면 영상 프롬프트로 해결하려 하지 않는다.

앞 컷 마지막 프레임을 다음 컷에 쓰면 연결뿐 아니라 얼굴·색·비율 변형도 전달될 수 있다. 원래 인물·공간 마스터와 함께 대조한다. 다른 각도의 컷을 억지로 같은 프레임에서 이어 만들지 않는다.

가려진 손, 새로 드러나는 얼굴, 반사, 글자, 물체 교환은 시간에 따른 오류 지점이다. 서사에 필요하면 대표 시험에 넣고 불필요하게 어렵다면 구도를 바꾼다. 로고·명패·한글은 편집/합성 가능한 별도 요소로 관리한다.
