## 첨부 간 충돌과 미확인 기술 주장

집필 스킬은 매 프롬프트의 같은 음성 설명을 요구하지만 프롬프트 스킬은 시트가 목소리까지 고정하므로 매번 설명하지 않아도 된다고 주장한다. 적용판은 반복 가능한 음성 프로필과 지원되는 음성 참조를 쓰고 실제 청취로 확인한다. 어느 문장도 음색 고정 보장으로 채택하지 않았다.

Prompt Writer 내부에서도 전체 블록 순서와 ‘카메라는 세 번째’가 충돌한다. 정리 순서는 작성 편의로만 사용한다. 팬 속도를 km/h로만 쓰기, 기준 없는 안개 밀도 백분율, 센서 조건 없는 화각 대응표, 특정 전환이 0.8초 미만이면 항상 하드 컷이 된다는 규칙은 채택하지 않았다. 30초 생성·영상 참조 최소 4초도 현재 제품·요금제 확인 없이 강제하지 않는다. 고정 FPS·렌즈·영어 지시·‘항상 긍정문만’ 등의 규칙보다 실제 장면과 사용자 조건을 우선한다.

작품의 인물·대사·구도·음원과 홍보용 참조 자산을 현재 작품에 그대로 재사용하지 않는다. 의상·제품·캐스팅은 사용자 정본을 따른다. 원본 스킬을 그대로 전역 설치하지 않고 관련 방법을 이 스킬의 문장으로 작성했다.

## 실증 상태

이 업데이트는 문서·절차 검증이다. 캐릭터의 연기 개선, Blender의 카메라 재현, 영상 Element의 한국어 음성 일관성을 실증한 결과는 아직 없다. 샘플을 생성한 뒤 실제 출력으로 검증한다. 제작자가 보고한 72시간·8,500크레딧·조회수를 소요 시간이나 성과의 약속으로 쓰지 않는다.
