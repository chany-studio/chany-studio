# 품질 판정과 근거

## 판정 대상

할리우드·Netflix를 하나의 스타일이나 점수로 정의하지 않는다. 아래는 이 스킬의 작업 기준이며 업계 인증 기준이 아니다.

| 영역 | 확인할 내용 | 결함 예 |
|---|---|---|
| 서사 | 욕구·갈등·선택·결과, 회차의 변화 | 설명만 있고 사건 없음 |
| 연기 | 의도, 경청, 반응 시점, 감정의 변화 | 말과 무관한 미소, 과장된 고개 움직임 |
| 시각 연속성 | 얼굴·의상·체형, 축·시선·동작·소품 | 컷마다 다른 인물, 빈손이 갑자기 물체를 쥠 |
| 화면·시간 품질 | 접촉·반사·변형·노출·초점, 실제 동작 | 정지화면은 정상이나 움직일 때 손이 합쳐짐 |
| 편집 | 인과·공간 이해, 정보량, 반응의 여백 | 대사 끝마다 기계적으로 자름 |
| 음향 | 화자·발음·싱크·소리 공간·음악 균형 | 마른 더빙, 누적 오프셋, 튀는 볼륨 |
| 사업·내용 | 제공 범위, 근거, 로고·문구·권한 | 무료/왕홍/매출 보장으로 확대 |
| 납품 | 규격, 자막, 재생, 자산·버전·프로젝트 연결 | 누락 파일, 깨진 링크, 옛 자막 출력 |

영역별 평가는 `미검토 / 수정 필요 / 목적에 맞게 통과`를 기본으로 한다. 점수가 필요하면 0=판단 불가, 1=장면 이해를 막음, 2=눈에 띄는 수정 필요, 3=목적에 맞음, 4=의도한 효과가 특히 잘 읽힘으로 보조 기록한다. 평균 점수로 얼굴 교체·잘못된 사업 주장·누락 음성 같은 중대 결함을 상쇄하지 않는다.

## 단계별 확인

- 이야기 검토: 대본을 읽고 인과·관계·허용 주장을 대조한다.
- 프리비즈 검토: 실제 낭독 시간을 재고 콘티/음성을 함께 재생한다.
- 대표 장면 검토: 기준과 결과의 인물·시선·소품·대사를 비교한다.
- 러프컷 검토: 전체를 보며 이해와 리듬을 평가한다. 필요한 컷만 추가한다.
- 최종 검토: 실제 출력 파일의 전체 재생과 청취, 문제 프레임, 자막·사업 문구, 납품 정보를 확인한다.

기록은 `대상 파일/버전`, `타임코드`, `관찰한 현상`, `심각도`, `수정 담당/방법`, `재검토 결과`로 남긴다. 생성기 성공 응답이나 파일 존재만으로 품질 통과라고 쓰지 않는다. 스틸만 봤다면 시간 품질·음향은 미검토다.

검토자는 가능한 도구로 직접 관찰한다. 사람에게 보여주지 않았다면 사람 검증은 미실시다. 접근할 수 없는 영상·청취 기능은 미검증으로 전달한다. 필수 근거가 없으면 해당 단계만 보류한다.

## 자동 검사와 수동 판단

`check_production.py`는 형식, 타임라인, 파일 존재, 대사 배치, 비용 합계, 주장 상태, 출력본 해시와 검토 기록 연결을 검사한다. 미디어를 디코딩하거나 음성을 듣고 입 모양을 판단하지 않는다. 검토 기록의 진실성을 증명하지도 않는다. 자동 통과는 수동 검수의 대체물이 아니다.

파일을 다시 출력하면 해시가 바뀌므로 이전 검토를 최종본에 자동 승계하지 않는다. 수정 영향에 따라 재검토하되 최종 출력의 전체 재생은 수행한다. 조회·기획만 요청된 작업에는 불필요한 미디어 검수를 요구하지 않는다.
