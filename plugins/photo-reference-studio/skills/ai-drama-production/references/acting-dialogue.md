# 대화·연기 수정

광고 낭독, 멈춘 표정, 근거 없는 놀람, 부자연스러운 티키타카를 수정할 때 읽는다. 공식 Acting Skill의 상대에게 향하는 연기 과제를 채택하고 한국어 업무 코미디에 맞게 조정했다. 원본의 특정 연기 학파 정의를 모든 장르의 정답으로 강제하지 않는다.

## 전체 대화부터 읽는다

한 줄을 떼어 감정어를 붙이지 않는다. 마지막 선택까지 읽은 뒤 이 대화에서 누가 무엇을 얻고 잃는지 적는다. 인물에게 ‘브랜드 혜택을 전달한다’, ‘시청자를 웃긴다’ 같은 제작 목적을 연기 과제로 주지 않는다. 인물은 자신의 일을 해결하려 한다.

| 항목 | 작성 기준 |
|---|---|
| 상황 | 방금 무슨 일이 있었으며 지금 무엇을 하고 있는가 |
| 함께 유지하려는 상태 | 예: 오늘 촬영은 끝내고 싶다. 공통 방향이 없는 갈등에 억지로 만들지 않는다 |
| 개인 동기 | 왜 그 사람에게 지금 중요한가 |
| 상대에게 원하는 결과 | 허락받기, 시간 벌기, 설명을 끝내게 하기, 물건을 바꾸게 하기 |
| 방해 | 상대의 이해관계·새 정보·시간·물건 상태 등 구체적 장애 |
| 방법 | 상대를 설득·떠보기·재촉하기. 듣고 결과를 확인하며 방법을 바꾼다 |
| 전환 단서 | 어떤 말이나 행동 때문에 다음 선택이 달라지는가 |
| 보이는 업무 | 대화와 함께 실제 하는 일. 의미 없는 손동작을 덧붙이지 않는다 |

표정은 원인 있는 반응으로 쓴다. ‘0.4초에 눈썹 2mm, 0.7초에 입꼬리’처럼 얼굴을 조립하지 않는다. 반대로 ‘무표정 유지’로 생각하는 과정까지 없애지 않는다. 상대의 말을 알아듣는 시간과 다음 말을 고르는 시간이 화면에서 읽혀야 한다.

## 한국어 업무 코미디

직무와 돈·시간·재고·마감의 이해관계에 맞는 대사를 쓴다. 현장에서 쓰지 않을 추상어, 같은 정보를 반복하는 질문, 혜택을 설명하기 위한 가짜 오해를 먼저 고친다. 대표의 실패는 그때 가진 정보로는 그럴듯한 시도여야 한다. 결과를 보고 새로운 정보를 얻거나 판단을 바꾼다. 매번 바보가 돼 직원에게 혼나는 구조로 만들지 않는다.

낭독하기 쉬운 문장과 실제 대화는 다르다. 상대가 이미 아는 주어·목적어는 자연스럽게 생략할 수 있다. 관계에 맞는 존댓말·호칭을 유지한다. 말끝을 모두 같은 음높이로 닫거나 모든 단어를 강조하지 않는다. 웃기려는 표정·마지막 웃음·매 줄 감탄사를 기본값으로 넣지 않는다.

대사량을 늘려야 원인이 이해되면 늘린다. 모델 길이 때문에 필요한 맥락을 자르지 않는다. 다만 말이 많다는 것만으로 티키타카가 생기지는 않는다. 각 발화가 앞말을 받아 거절·보완·협상·수정하는지 확인한다.

## 짧은 연기 블록

```text
ACTING — [인물 ID]
지금 해결하려는 일:
상대에게 얻으려는 것 / 그 이유:
처음 쓰는 방법:
상대의 어떤 말·행동을 듣고 판단이 달라지는가:
달라진 뒤의 방법:
말하지 않을 때 확인하는 것:
업무 행동과 대사 연결:
말투·음성 기준:
```

다인 대화는 화자·정확한 대사·청자·화면 안/밖을 연결한다. 화면 밖 발화 때문에 카메라가 뜻하지 않게 화자를 찾아가거나 자리가 바뀌지 않도록 한다. 듣는 사람에게도 판단할 일을 준다. 모든 사람에게 같은 컵 돌리기나 고개 끄덕임을 배분하지 않는다.

반응이 중요한 말에는 듣는 사람의 얼굴을 보여 줄 구도가 필요하다. 대화가 가능한 업무 동작이나 입장 중에도 대사를 시작할 수 있다. 앉고 정면을 본 다음에만 말을 시작하는 패턴이 광고 낭독을 만드는지 확인한다. 각 인물의 음성 프로필은 독립 생성에도 전달하고, 장면마다 달라지는 것은 의도와 강약으로 제한한다. 이미지 시트의 재사용만으로 음색이 고정된다고 보장하지 않는다.

## 가상 연습 장면

다음은 연기 과제를 설명하기 위한 새 연습 예이며, 촬영·생성 결과가 아니다.

회의 진행자는 시작 시각을 지키고 싶고, 동료는 바뀐 회의실을 참석자에게 알려야 한다. 진행자는 이미 울리는 휴대전화를 보고서야 사람들이 옛 회의실에서 기다린다는 사실을 이해한다.

| 대사 | 실행할 일과 듣는 반응 |
|---|---|
| 동료: “다들 아래층에 있대요.” | 문제를 알리고 진행자가 안내하러 갈 수 있는지 살핀다 |
| 진행자: “링크는 바꿨는데.” | 자신의 조치가 충분했는지 확인하며 휴대전화를 본다 |
| 동료: “출력한 안내문에는 그대로예요.” | 상대가 놓친 정보 하나를 보완한다. 혼내듯 말하지 않는다 |
| 진행자: “먼저 시작해요. 제가 데려올게요.” | 새 정보를 받아 역할을 나눈다. 결정 후에만 문으로 움직인다 |

말이 끝나기 전에 퇴장하도록 강제하지 않는다. 휴대전화 확인, 판단, 출발의 순서와 상대의 듣는 반응을 실제 장면으로 확인한다.

## 검수와 수정

정상 속도로 전체 장면의 소리와 화면을 확인한 뒤 타임코드를 적는다. 검사 항목은 정확한 대사·화자, 한국어 발음, 호흡, 발화 겹침, 듣는 반응, 전환의 원인, 목소리 일관성, 싱크, 웃음의 여백이다.

| 증상 | 다음 수정의 우선 후보 |
|---|---|
| 또박또박 홍보문처럼 읽음 | 대사 목적과 청자를 명확히 하고 실제 구어로 낭독 점검; 음성·연기 참조 시험 |
| 얼굴만 움직이고 생각이 안 읽힘 | 상대 반응을 보고 무엇을 결정하는지 지정 |
| 모든 대사 전 긴 침묵 | 필요한 전환 한 곳에만 여백; 나머지는 업무 흐름 유지 |
| 반응이 대사보다 먼저 나옴 | 반응을 일으키는 정확한 말 이후로 순서 연결 |
| 대사가 잘리거나 화자가 바뀜 | 발화 시간·음성 입력·컷 구조 확인; 필요한 지점에서 블록 분할 |
| 좋은 연기에 손 오류만 있음 | 손이 안 보이는 구도, 삽입 컷·편집·국소 수정 검토 |

자막은 대사 내용 확인, 무음 화면은 동작 확인에 쓰인다. 둘만으로 억양·자연스러운 청취를 검증했다고 하지 않는다. 도구가 소리를 전달하지 못하면 음성 판정은 보류하고 다른 검사는 계속한다.
