# 편집·음향·납품

## 전역 타임라인

FPS는 소스와 납품 기준으로 정한다. 23.976은 `24000/1001`처럼 유리수로 보관한다. 편집 구간은 시작 포함·끝 제외 프레임 `[start,end)`다. 소스 인/아웃과 전역 위치를 구별한다. 음성은 샘플 단위 편집이 가능하며 제작표의 프레임 환산은 위치 검사 용도다.

장면별 반올림 시간을 누적하지 않는다. 장면·대사·자막을 최종 타임라인에 배치하고 수정 뒤 오프셋을 다시 확인한다. J/L 컷과 대사 겹침은 음성 전역 구간으로 표현한다. 화면 구간 중복과 전환 효과의 소스 중첩은 다르다.

## 편집 판단

러프컷은 이야기 이해와 감정 변화부터 본다. 다음으로 시선·동작, 반응 타이밍, 장면 밀도를 다듬는다. 설명 사이를 무관한 예쁜 이미지로 채우지 않는다. 공간이 필요한 순간에는 전체 구도를, 감정 변화에는 적절한 거리의 얼굴·행동을 보여준다.

잘린 접촉·시선 점프를 디졸브로 무조건 덮지 않는다. 앞뒤 동작 선택, 삽입 컷, 화면 밖 소리 등 의미에 맞는 해결을 고른다. 필요하면 숏리스트로 돌아간다.

## 음성·음향

대사, 룸톤·환경음, 폴리·효과, 음악을 별도 트랙/스템으로 보관한다. 호흡·억양·화자 음색·발음, 테이크 사이의 소리 공간을 듣는다. 넓은 방·복도·야외에 같은 마른 TTS 소리를 쓰지 않는다. 잔향이 명료도를 해치지 않게 한다.

연속된 환경음은 컷 연결을 돕지만 잘못된 얼굴·동선을 합격으로 만들지 않는다. 음악이 말을 가리면 자동화나 덕킹을 쓰고 실제로 듣는다. 특정 LUFS를 모든 숏폼 규격으로 삼지 않는다. 납품 요구와 측정값을 비교하고 이어폰·스피커에서 확인한다. 클리핑·클릭·레벨 변화·음소거·입 모양 오프셋은 타임코드로 기록한다.

원어 대본·자막·화자·시간표와 음향 스템을 보관한다. 현지화 대사가 길어지면 자동 속도 증가보다 문장·컷 길이·립싱크를 다시 조정한다.

## 색·글자·출력

소스·프로젝트·출력 색공간과 HDR/SDR 변환을 확인한다. 영화 느낌을 위해 LUT·그레인·블랙바를 일괄 추가하지 않는다. 피부·의상·로고부터 컷마다 맞춘다. 업스케일은 누락된 연기나 손동작 복구를 보장하지 않는다.

로고·명패·제품 문구는 허용된 원본을 합성하고 필요하면 추적한다. 세로·가로 버전은 구도·시선·자막 여백을 재검토한다. 작은 화면 가독성과 실제 플랫폼 UI 가림을 확인한다.

납품은 요청한 마스터·플랫폼 버전, 자막·대본, 스템, 자산 출처·사용 범위, 프로젝트·재연결 정보와 미해결 결함으로 구성한다. Netflix 문서 참고를 IMF·Dolby·Netflix 인증으로 표현하지 않는다.

마지막 검사는 편집기 미리보기 대신 최종 출력 파일 전체에서 한다. 첫/끝 프레임·길이·음성 싱크·자막·CTA를 확인한다. 프로젝트 열기·미디어 연결·출력 재현 여부도 각각 기록한다.
