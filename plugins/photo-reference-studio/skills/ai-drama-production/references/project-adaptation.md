# 프로젝트 적용

현재 프로젝트의 지침, 기존 브리프·상태, 최신 대본, 승인된 캐릭터·의상·공간 자산과 공개 범위를 확인한다. 이전 고객의 설정이나 승인 기록을 가져오지 않는다. 사용자 결정과 자산 버전을 연결하고 빠진 값은 가정 또는 확인 필요로 남긴다.

반복 캐릭터와 대안 버전은 별도 ID로 관리한다. 얼굴·의상·목소리·배경의 적용 범위를 적고 서로 다른 버전을 섞지 않는다. 게스트와 화면 속 사진은 주연과 구별한다. 브랜드가 실제 제공하는 서비스와 극 중 인물의 희망·농담·창작 사건도 구별한다.

기존 프로젝트 기록을 정본으로 사용한다. Chany’s Studio에서 관리하는 프로젝트는 `chany-project`의 브리프·상태를 사용하고, 이 스킬을 설치했다는 이유로 새 지침 파일이나 외부 시스템 설정을 만들지 않는다. 내부 자산·출처 경로·미공개 대본·고객별 적용 프로필은 공개 플러그인에 넣지 않는다.

작품마다 목적·관객·길이·화면비·FPS·공개 위치를 확인한다. 양식 속 수치는 예시이며 새로운 작품의 승인이나 납품 규격이 아니다. 최종 출력의 버전, 실제 재생·청취 범위, 미해결 결함과 공개 승인 상태를 분리해 인계한다.
