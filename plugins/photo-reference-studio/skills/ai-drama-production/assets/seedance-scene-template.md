# Seedance 장면 프롬프트와 검수 카드

작성용 양식이다. 참조가 실제로 붙기 전에는 그대로 제출하지 않는다. 불필요한 항목은 삭제하고 대사는 정본과 대조한다.

## 제작 설정 — 사이트/도구에서 확인

장면·대본 버전:
모델 / 길이 / 화면비 / 해상도 / 음성:
무제한 또는 승인 비용 / 동시 실행 상태:
현재 지원하는 참조·음성·연장 기능:
제어 방식: 연속 한 컷 / 순서만 지정 / 시간표 지정 / 보조 화면
편집에서 필요한 반응 얼굴 / 별도 삽입 컷:

## 생성기에 넣을 내용

```text
REFERENCES
[실제로 연결된 ID]: 사용할 속성 / 제외할 속성 / 적용 구간.
충돌하는 자산이 있다면 속성별 우선순위.

SCENE
이 장면에서 벌어지는 일. 시작 때 원하는 것과 끝 때 달라지는 것.

SPACE AND START STATE
장소, 시간, 인물 위치·방향·시선, 화면 좌우, 소품 시작 상태.
카메라 축과 보일 배경.

ACTION AND DIALOGUE
발화 순서. 화자 ID: “정확한 한국어 대사”. 듣는 상대와 반응의 원인.
동작은 어느 대사 전/후인지 지정. 필요한 구간에만 가정 또는 측정된 시간.
끝 상태와 이어질 장면의 연결.

CAMERA
각 컷의 시작 구도 → 필요한 이동 → 끝 구도. 컷 여부와 유지할 시선축.
행동·물체 접촉을 확인하는 데 필요한 화면 범위.

ACTING
인물별 원하는 결과, 이유, 방해, 상대에게 쓰는 방법, 전환 단서.
듣는 동안 판단하는 것. 말투와 음성 기준.
독립 생성에 다시 전달할 동일 인물 음성 프로필과 실제 연결된 음성 참조.

LOOK AND SOUND
정본 공간의 빛·색·재질. 대사 언어, 룸톤, 행동과 맞는 효과.
음악의 유무. 필요한 글자·로고의 생성/후처리 구분.

KEEP
반드시 유지할 얼굴·의상·좌석·물건·대사·끝 상태만 짧게 명시.
```
