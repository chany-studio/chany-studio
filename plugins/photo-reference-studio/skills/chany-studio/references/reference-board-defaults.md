# Default reference board

Read [photo reference execution](photo-reference-execution.md). “인스타그램용 광고 사진” asking for a product's composition/lighting is still styling, not ad-case benchmarking. Behance remains the default; Production Paradise requires a named-source or photographers' portfolio request. Do not substitute retailers when a source cannot be opened.

For an unspecified still-photo styling provider (not advertising examples), use Behance through `chany-reference-board`: **6 actual inline images** by default. An explicit positive count overrides six; zero skips research. Never split an unspecified request across several sites. Follow [Behance search and display](behance-reference-search.md) and [bounded recovery](reference-recovery.md). Never count links, HTML or metadata as displayed images.

Use [curated sources](curated-reference-sources.md) and [reference-sources.json](reference-sources.json) to select an appropriate source by purpose, at most two per discovery task. A named source or supplied reference takes priority; keep specialist source boundaries. A supplied reference skips discovery unless alternatives are requested. Explicit requests outside the default directory use a separate named-source lane, never expand the Pinterest preview allowlist or silently replace a requested source.

Video requests follow [video-first experience](video-first-experience.md), not this static board. [Instagram-first advertising](instagram-ad-reference.md) uses three total candidates; explicit Meta-only research retains its six-ad default; curated video discovery proposes three unless a count is given. Do not mix these count contracts.

Show source, fit and a short observation per candidate. If a board is incomplete, report requested/visible/missing counts and the access limit, then use the existing single selection/production decision. Preserve the product/service source, exact copy and paid-generation/upload boundaries.
