# Default visual references: Pinterest + MeiGen

For an unspecified visual-reference provider, or an explicit Pinterest + MeiGen request, `chany-reference-board` coordinates one board. Default total is **10**: Pinterest 5 and MeiGen 5. An explicit positive total overrides 10; divide evenly and give the odd extra to Pinterest unless the user specifies the split. One requested image uses Pinterest; zero skips research. An explicit provider-only request uses only that lane; do not force a second provider. Meta ad benchmarking, professional-photo and award-archive requests retain their specialized owners.

Run Pinterest through its search/preview rules and MeiGen through `chany-ai-prompt-reference`. These are separate source pools, not a relaxed Pinterest allowlist. MeiGen previews must come from the inspected MeiGen entry/tool; never send them to the Pinterest-only preview tool. Read [reference-recovery.md](reference-recovery.md) for bounded automatic retries. Do not recursively request a generic board from the MeiGen lane.

Show all accepted candidates as actual inline images in the current conversation, continuously numbered with provider, source, fit and concise visual analysis. Add the available MeiGen source-prompt analysis; never invent an unpublished prompt. Preview URLs, link lists, HTML and metadata are not visible images. Resolve display capability before searching each lane. If a lane cannot display images, continue the other lane, disclose the shortfall and offer one decision; do not ask the user to authorize another routine search or silently fill all slots from the other provider.

Track total requested/visible/missing and each lane's target/visible count. An incomplete board remains incomplete until the user accepts a reduced scope. After research, recommend one direction across the board, not one approval per provider. For production requests combine the selection and paid-generation decision as described in the recovery contract. Preserve source product, approved copy and GPT Image 2 default.
