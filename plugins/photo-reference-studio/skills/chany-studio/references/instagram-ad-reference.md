# Instagram-first advertising references

For ad inspiration in video, image or carousel form, start with Instagram through the separate curated branch of `chany-reference-board`. Use Meta Ad Library through `chany-meta-ad-research` as a complementary source when paid-ad execution or additional accessible examples are needed. Keep six default providers overall; Ads of the World is available only on explicit request through its existing specialist. A selected user reference skips discovery; an explicit provider, count or zero overrides these defaults. A Meta-only request stays Meta-only.

## Small, relevant shortlist

Reuse the product/service brief, placement and any supplied accounts or directory. Search the relevant industry/product and inspect accessible original posts, carousels or Reels using tools actually available in this host. Prefer a supplied relevant account/link before broad search. Start with one source and use at most two. Do not turn the user's directory into a permanent list of recommended sites or accounts.

Default to **three total candidates** across the Instagram-first job, including any Meta supplements; do not automatically add six more. An explicitly Meta-only job retains the specialist six-ad default. Pass the remaining candidate count explicitly to the Meta owner when supplementing. Honor a requested count, and zero skips research. Instagram-only requests cannot be silently filled from Meta. If Instagram access is blocked in a generic ad search, explain the source change before using the allowed Meta fallback; mark Instagram unobserved. Stop with an honest shortfall if neither source yields inspectable material. Do not bypass login, access restrictions or use undocumented private APIs.

## Observe before comparing

For each candidate record the original URL, visible creator/brand, visible publication date (or unknown), observation date, format, what was actually viewed and why it fits the user's product/service. Keep source provenance when supplementing from Meta. Separate organic content, visibly disclosed partnership/sponsorship, and an advertisement observed in Meta Ad Library. An Instagram post or Reel alone does not prove paid delivery; a paid-partnership label does not prove paid-media delivery or sales. Likes, views, appearance and time on air do not prove conversion performance. Unknown publication dates are not proof of a current trend.

Inspect actual images/carousel pages and use `chany-video-reference-ingest` for video observation. A thumbnail or snippet is a discovery lead, not evidence of motion, timing, voice, music or full copy. Show actual media where the host permits; otherwise give the source link and the observation limit. Do not label unviewed leads as completed visual analysis or final recommendations. Apply [watch-before-recommending](instagram-video-verification.md) to every Reel finalist and keep caption-only leads outside the ranked list.

Compare only observable opening/hook, product or service demonstration, pacing, copy, evidence and CTA. Clearly separate proposed changes from the observed reference. Apply the mechanisms to the user's real product facts; no invented endorsements or results. Public availability alone does not authorize source replacement or republication. The user's request to analyze public references permits necessary connected analysis of returned direct media under the verification contract; private uploads and paid generation have separate boundaries. Keep the existing original-remake versus authorized-source-edit boundary.

## Product-matched popularity search

For high-view, high-like or high-share Instagram examples, follow [Apify Instagram research](apify-instagram-research.md) through the existing reference owner. Reuse the product brief, verify the live search and share-count options, and compare only actually retrieved metrics. Missing shares remain unknown; popularity is not conversion evidence. Apify is an optional access method, not another reference provider.

## Capability and handoff

Metricool is optional for already configured competitor accounts and exposed post/Reel analytics. It is not a universal Instagram keyword, hashtag, audio or visual search tool, and installation is not a prerequisite. Follow [Metricool research](metricool-reference-research.md); empty analytics do not establish that a post does not exist.

This branch ends with the shortlist and observed analysis. Preserve the existing output owner and brief: `chany-campaign-video` for ordinary product/service films, `chany-ad-creative` for static/carousel ads, and an already selected video specialist when applicable. Search consent is not paid-generation or publishing consent. The Pinterest query rules, preview server and image-board completion requirements apply only to the Pinterest lane, never Instagram or Meta.
