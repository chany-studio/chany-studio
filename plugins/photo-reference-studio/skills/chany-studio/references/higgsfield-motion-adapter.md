# Higgsfield motion execution

Scope: Higgsfield AI Motion Designer and available Higgsfield motion-editing workflows only. This update does not add Adobe's separate AI Assistant, Runway or ElevenLabs integrations.

## Capability gate

- Discover the active Higgsfield workflow catalog and load the matching instructions before execution. Do not assume a workflow name exists. For native After Effects work, verify a callable bridge, target project/composition, editable-layer operations and render/export support. An installed app, blog or slash-command example is not proof.
- Higgsfield's announcement describes native After Effects layers and a `/use-after-effects` entry point. Do not register or promise that slash command in Claude or ChatGPT. Use the host's actual callable tools. Never assume a generic video-editing workflow provides native After Effects access.
- If native AE is unavailable but the catalog exposes a suitable Higgsfield motion-editing workflow, explain its output format before choosing it. Do not substitute a flattened render when the user requires editable AE source without agreement.
- If neither exists, stop execution at a plan-only handoff. Do not install bridges, buy subscriptions or switch providers automatically. Document capabilities observed in this session rather than hard-coding availability from this release.

Before billable operations apply [higgsfield-runtime-contract.md](higgsfield-runtime-contract.md). Record the operation, target project, source assets, scope, quote/unknown cost, approval, result reference and status. Native project edits need project snapshots/versioned outputs; generation jobs use [media-job-ledger.md](media-job-ledger.md). An ambiguous response requires inspecting the original operation before resubmission.

Do not promise unlimited length/resolution, pixel-perfect preservation or improved conversions. Verify supported duration, fonts, dimensions, export and subscription requirements live. Keep these capabilities optional: ordinary image ads and campaign-video generation must work without After Effects.

Source checked 2026-09-15: [Higgsfield AI Motion Designer announcement, 2026-09-10](https://higgsfield.ai/blog/ai-motion-designer-after-effects-gpt). Provider descriptions establish intended capability, not an end-to-end test in the current host.
