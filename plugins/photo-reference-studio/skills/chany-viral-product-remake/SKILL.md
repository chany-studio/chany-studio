# Chany Viral Product Remake

Make the common “reference link + my product” job feel like one simple workflow while preserving product truth, rights, and paid-generation controls. This skill owns the beginner-facing intake, fast remake plan, and handoff; the existing specialist skills still own capture, campaign scenes, generation, assembly, and release review.

Every user-facing turn follows the shared [beginner experience contract](../chany-studio/references/beginner-experience.md): quick start by default, plain Korean without internal field names, and no extra checkpoint beyond the still and video confirmation cards required for video production.

Read [references/fast-remake-contract.md](references/fast-remake-contract.md), the shared [video reference teardown](../chany-studio/references/video-reference-teardown.md), [product insertion pipeline](../chany-studio/references/product-insertion.md), and [live model routing](../chany-studio/references/latest-model-routing.md). For an Instagram, TikTok, YouTube, or other page link, first use `chany-video-reference-ingest`; a public URL is evidence for observation, never permission to download, upload, transform, or republish its footage.

## Choose one execution path

- **새로 만들기 — default for third-party links:** observe or capture only what the user can lawfully show, extract the transferable hook, timing grammar, camera behavior, reveal logic, texture/material metaphor, information order, and sound function, then create an original shot sequence with the user's product, setting, copy, audio, and brand. Do not reproduce distinctive frames, branded pixels, people, music, narration, or a substantially identical sequence.
- **제품 교체 — only for authorized source media:** require a usable attached/local clip or authorized capture and the user's confirmation that they own or may modify it. Route one bounded object replacement through `chany-campaign-video`'s Genjutsu revision mode. The page URL by itself is insufficient source media and insufficient permission.
- **분석만:** stop after the observed beat map, product-fit explanation, and original remake plan. Do not generate or imply that a finished video exists.

When rights or source quality are unclear, select 새로 만들기. Never ask a beginner to choose a model or internal workflow.

## Fast workflow

1. Read the link or attached clip through `chany-video-reference-ingest`. State the evidence ceiling honestly: visible excerpt, complete authorized capture, or local source file.
2. Inspect the user's product images through `chany-product-assets`. Prefer front, side, back, label, cap/opening, and material details when available, but proceed with fewer views when the visible shot design does not require the missing side. Never invent label text or hidden geometry.
3. Produce the compact remake brief from the contract: hook, six beats or fewer unless the reference genuinely needs more, product reveal, camera/motion, material interaction, copy/audio role, end frame, and one product-preservation rule per shot.
4. Route original scene design to `chany-campaign-video`. Use one governing still per identity-sensitive scene, then `chany-media-production-loop` for paid generation and `chany-video-assembly` for the accepted final cut. Use `chany-motion-design` only when a requested hook, logo, benefit, or CTA layer needs it.
5. For an authorized product swap, send the accepted source clip, one target object, preserve list, governing product references, and source timing to the Genjutsu revision route. Review the entire clip, not only the replaced object.
6. Deliver the finished vertical video plus a concise production note: source/reference status, what was transferred, what was newly designed, product-match result, copy/CTA, and any rights or publication limit. Run `chany-publication-review` when the user requests publishing, a regulated gate applies, or the rights/disclosure state remains material.

## Beginner interaction

If the user already supplied a link and product images, do not start a long interview. Infer 9:16 and the observed reference duration for a Reel/Short unless the user names another placement. Ask only one bundled question when a blocking item is missing: the product source, the intended product/service, or whether the supplied source clip is theirs to modify.

Before paid work, tell the user once that two cards will appear: first the governing product image, then the video. The first card shows the chosen reference construction in one sentence, exact product/copy, upload disclosure, live model/workflow, output count, and live cost. The second card shows the accepted still, scene count, duration, ratio, audio plan, actual video operation, and live cost. A changed product, reference, copy, duration, model, count, or source upload requires a new card.

This skill is not a downloader, scraper, engagement-performance predictor, or authorization shortcut. It does not own long-video extraction (`chany-shortform-recut`), independent multi-variant editing (`chany-ad-variants`), or general campaign strategy (`chany-studio`).
