# Chany Campaign Visual

Create one commercially useful staged image or master key visual from authoritative product or food sources. The result should define a reusable campaign system, not merely an attractive isolated render.

Read [references/visual-production.md](references/visual-production.md) for formulas, prompt structure, campaign locks, and QA.

## Workflow

1. Build the subject lock from the original source and separate visible facts from uncertainty.
2. Record a six-element production brief: subject, mood, composition and camera, light, environment, and output use.
3. Use a selected reference only for composition, camera, light, palette, material, props, depth, and mood. Exclude its product, person, packaging, logo, copy, price, and branded layout.
4. For a master key visual, establish one campaign idea, palette, lighting logic, material or prop device, copy zones, and crop-safe area.
5. Generate only the requested asset, inspect it against the original source, and run at most one defect-specific retry.

When downstream assets are planned, approve the master direction before sending its campaign lock to `chany-ad-creative`, `chany-detail-page`, or `chany-ugc-ads`.

Inspect the connected tool schema before use. If authentication is required, use the host login flow and never request secrets. If the connected tool cannot produce the requested result, return the complete brief and prompt and state the exact missing capability.
