# Chany Award Ad Reference

Use award and campaign archives as a distinct strategy lane. Before discovery, read the shared [specialist reference lane contract](../chany-studio/references/specialist-reference-lane.md) and this lane's [source policy](references/source-policy.md). The contract owns the L1-then-optional-direct-L2 query, count, display, rights, recovery, and shortfall rules; this file adds only what is specific to the award archives.

## Required result

- Resolve `target_count` from the user's explicit positive whole number or default to `6`.
- Search only public pages on Ads of the World, D&AD, and The One Show with the taxonomy L1 subject first and at most one direct L2 child.
- Prefer campaign cases with a legible hero asset, identifiable advertiser or entrant, visible source page, and an idea that can be abstracted without copying execution. For three or more results, use at least two of the approved archives when enough qualifying results exist.
- Show exactly `target_count` distinct actual images in the current conversation, using each case's legible hero visual. Under each image include archive, source page, query, campaign or work title when visible, fit note, Visual DNA, message mechanism, and the branded elements that must not transfer.
- Never infer award status, effectiveness, or commercial results beyond what the source page states.

On a shortfall, report the incomplete diagnostic from the contract. Do not add Pinterest, MeiGen, Production Paradise, Stocksy, ShotDeck, Death to Stock, or another provider without a new user request.
