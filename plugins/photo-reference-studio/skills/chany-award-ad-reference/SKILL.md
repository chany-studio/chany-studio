# Chany Advertising Case References

Use Ads of the World as the campaign-idea lane. Keep the existing skill ID for saved calls; an archive listing is not evidence of an award. Before discovery, read the shared [specialist reference lane contract](../chany-studio/references/specialist-reference-lane.md) and this lane's [source policy](references/source-policy.md). The contract owns the L1-then-optional-direct-L2 query, count, display, rights, recovery, and shortfall rules; this file adds only what is specific to the award archives.

Every user-facing turn follows the shared [beginner experience contract](../chany-studio/references/beginner-experience.md): quick start by default, plain Korean without internal field names, and one confirmation card before any paid generation.

## Required result

- Resolve `target_count` from the user's explicit positive whole number or default to `6`.
- Search only public pages on Ads of the World with the taxonomy L1 subject first and at most one direct L2 child.
- Prefer campaign cases with a legible hero asset, identifiable advertiser or entrant, visible source page, and an idea that can be abstracted without copying execution. Use this single archive; do not add providers just to vary the results.
- Show exactly `target_count` distinct actual images in the current conversation, using each case's legible hero visual. Under each image include archive, source page, query, campaign or work title when visible, fit note, Visual DNA, message mechanism, and the branded elements that must not transfer.
- Never infer award status, effectiveness, or commercial results beyond what the source page states.

On a shortfall, report the incomplete diagnostic from the contract. Do not add Pinterest, Production Paradise, Stocksy, ShotDeck, Death to Stock, or another provider without a new user request.

For video campaign examples, pass the actual accessible clip/page to `chany-video-reference-ingest` before discussing timing, motion or audio. Use the video-first observation and preview rules instead of counting a hero image as an inspected video. If playback is unavailable, return a clearly labelled discovery lead, not a completed video analysis.
